- 수기 구간 직접 HH:mm/공통 시계. 긴 분 단위 드롭다운 폐기, 범위/비중복 검증과 정확한 입력 보존.

- 기존 NAS Supabase 연결 기준. 관리자 인증·Studio 하위 경로·기존 DB 보존. 새 클라우드 중복 생성 없음.
