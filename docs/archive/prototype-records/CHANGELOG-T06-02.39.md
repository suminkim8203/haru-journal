# 02.39 — 휴식/중단 입력 UI 재설계

요약: 02.38의 긴 분 단위 드롭다운을 폐기하고 직접 입력·공통 시계·빠른 종료로 변경했습니다. HTML 시안 반영이며 실제 앱/API/SQL은 변경하지 않았습니다.

- 시작·종료 HH:mm 직접 입력, 0917→09:17 이탈 시 정규화. 저장 정밀도는 유지하며 반올림하지 않음.
- 공통 시계로 시/분을 분리해서 선택. 범위 밖 비활성. 분 버튼은 표준 5분 간격 12개+경계/현재 분, 긴 목록 없음.
- 시작 시각에서 5/10/15분 뒤 종료. 실행 범위를 초과하는 빠른 종료는 비활성.
- 범위 밖 직접 입력은 오류 안내/저장 차단, 실행 범위 변경 후 기존 값은 덮어쓰지 않음. 기존 완료/타이머/배치/단상·회고·집계/과제 필수 기능 유지.

직접 입력 마크업, 범위 제한 시/분 선택·정확한 현재 분·빠른 종료/경계·자정 넘김·범위 밖 값 보존 및 기존 저장 검증 확인 통과. 스크립트 구문 검사 통과. 모의 DOM은 실제 브라우저/모바일 시각 및 사용감 검증이 아니며 아직 미완료입니다. 다음은 입력 UI 확인 후 실제 구현입니다.
