# T06 02.10 검토 안내 및 결정 기록

한 줄 요약: 합의한 루틴 기능을 화면에서 확인하는 단계입니다. 새로운 서버 개발 단계로 넘어간 것이 아닙니다.

## 현재 프로젝트에 실제 구현된 기능

02.10 HTML의 첫 화면에서 `루틴 예시 추가`를 누르면 고정 시각 루틴과 시각 없는 루틴이 각각 7일씩 생성됩니다. 기존 예시 계획을 덮어쓰지 않습니다.

### 직접 검토 순서

1. 일간에서 `루틴 예시 추가`를 누릅니다. 왼쪽 루틴 계획을 펼칩니다. 스트레칭은 08:00 예정 블록이 있고 독서는 시간 미정이어야 합니다.
2. 독서를 타임라인에 끌어 배치하거나, 제목 선택 → 시간 관리 → 시간 배치로 배치합니다. 이 날짜만 변경되고 개별 수정 표시가 생겨야 합니다.
3. 오늘 할 일을 완료한 뒤 다음 날짜로 이동합니다. 다음 날짜의 같은 할 일은 미완료여야 합니다.
4. 계획 화면에서 루틴 계획을 선택합니다. 날짜별 할 일 제목 → 수정 → 내용 변경 → 적용 범위 확인으로 이동합니다.
5. 기본 `이 날짜만`과 `이 날짜부터 이후 반복`을 비교합니다. 이후 반복을 선택하면 보호되는 날짜와 이유가 보여야 합니다. 변경 확정 전에는 저장하지 않습니다.
6. 아직 실행하지 않은 날짜에서 수정 → 이 날짜 건너뛰기를 선택합니다. 해당 날짜의 예정 배치는 없어지고 다음 날짜는 유지되어야 합니다.
7. 다른 날짜에서 수정 → 이 날짜부터 반복 중단을 선택합니다. 보존 항목을 확인하고 확정합니다. 기존 실행 기록과 개별 수정은 유지되어야 합니다.
8. 돌아보기 → 계획 결과에서 해당 루틴 계획을 선택합니다. 완료율과 건너뛰기·중단 제외 목록을 확인합니다.
9. 직접 생성하려면 새 계획 → 루틴 계획 → 계획 저장 → 반복 할 일 입력 순서로 진행합니다.
10. 모바일에서는 드래그 대신 접이식 할 일 목록과 시간 관리의 명시적 배치 버튼을 사용합니다.

## 구현되지 않은 기능과 확정된 요구사항

다음 요구사항은 사용자 동의가 확인됐으며, 02.10에 반영했습니다.

- 일반 계획 / 루틴 계획 선택.
- 계획 기간 안에서 할 일별 매일 반복 기간 설정.
- 정해진 시각에 반복 / 시각 없이 반복 선택.
- 날짜별 독립 완료, 미완료 자동 이월 없음.
- 날짜만 수정 / 이후 반복 수정, 과거·실행·완료·개별 수정 보존.
- 건너뛰기와 반복 중단 구분.
- 건너뛰기는 완료율에서 제외하고 별도 표시.
- 반복 아이콘과 짧은 루틴 표시 사용. 색만으로 의미를 전달하지 않음.

요일별 반복·반복 재개·취소/복원 등 추가 정책과 서버 구현은 이번 범위 밖입니다. 구현 세부의 미확정 제약은 변경 기록에 따로 적었습니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

서버 서비스 도입 없음. 브라우저 임시 저장만 사용하며 이전 버전 상태는 자동으로 옮기지 않습니다.

## 확인이 필요한 부분과 다음 단계

- 우선 반복 수정의 두 단계 화면과 대상/보존 설명이 이해하기 쉬운지 확인합니다.
- 표시 크기·색·위치, 모바일 조작은 사용자 화면 검토가 필요합니다.
- 루틴 화면 합의 후 전체 흐름과 미결정 정책을 점검하고 개발용 요구사항·잔여 개선 목록으로 정리합니다.
- 그다음 데이터 구조·권한·저장 정책·기술 선행 조건을 확인한 뒤 실제 개발로 진행합니다.
