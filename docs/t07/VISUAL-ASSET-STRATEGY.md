# Haru 시각 자산 전략 — 대표 화면 검토 01

요약: 현재 월간·돌아보기 검토 화면의 인공적인 느낌은 자료가 부족해서보다 **CSS가 실제 획의 밀도와 끝 모양을 덮어쓴 것**, 모든 선과 면을 균일하게 처리한 것에서 온다. 레이아웃과 글자는 HTML/CSS로 유지하고, 실제 재료의 불균일함이 의미 있는 세 지점만 이미지 자산으로 바꾼다. [세 단계 비교 시안](studies/Haru-visual-asset-study-01.html)은 검토용이며 공개 서비스에는 아직 적용하지 않았다.

## 조사 기준과 인공적으로 보이는 이유

- 기준 화면: `Haru-schedule-structure-study-05.html`의 제호·일간·주간·월간·돌아보기 한 화면. 실제 앱은 별도이며 이 화면의 월간 계획 획 자체는 아직 배포되지 않았다.
- 기존 월간은 `highlight-amber-01.png`를 **마스크 모양으로만** 사용하고 그 안을 CSS의 단색·규칙적인 그라디언트로 다시 채운다. 원본 PNG 안의 미세한 농도는 사라지고, 마스크를 106% × 360%로 늘리면서 양끝과 테두리가 지나치게 정돈되어 보인다.
- 종이는 균일한 `#f5f5f5` 면이고 구획선은 전부 같은 1px 선이다. 글자와 획이 놓인 물리적인 층 차이가 거의 없다.
- 돌아보기 숫자의 밑줄은 `clip-path: polygon(...)`으로 만든 규칙적인 도형이었다. 첫 3단계 시안에서 긴 PNG를 숫자 아래의 작은 크기로 축소하자 선이 깨져 보였고, 오른쪽으로 올라가는 각도도 그대로였다. 사용자 피드백 후 이 용도에 맞는 짧고 거의 수평인 SVG를 새로 그렸다.
- 첫 3단계 시안에는 날짜 경계를 가리려는 종이색 가상 요소가 **계획명 뒤를 하얗게 지우는 문제**도 있었다. 이 가상 요소를 삭제했다. 날짜 경계는 채워진 획 아래에서 희미하게 비치며 텍스트 뒤에도 흰 면을 올리지 않는다.
- 후속 검토에서 형광펜 아래 날짜선이 여전히 선명하다는 피드백을 반영했다. 3단계에 한해 **형광펜 이미지의 실제 알파 형태 안에서만** 종이색을 겹쳐 선의 대비를 줄였다. 처음 30%에서 50%로, 다시 15%포인트 높인 65%로 조정했다. 계획명 뒤의 별도 흰 면은 다시 넣지 않았고, 그 위에 원본 형광펜 이미지의 결·양끝 농도를 그대로 올린다.
- 기존 동그라미 PNG는 실제 자산이지만 같은 크기·위치로 여러 번 쓰면 복제된 도장처럼 보인다. 월간의 모든 날짜에 사용하지 않는다.

## 요소별 선택

| 요소 | 현재 화면·자산 상태 | 선택 방식 | 적용·보류 이유와 비용 |
|---|---|---|---|
| 지면과 종이 배경 | 단색 CSS `#f5f5f5` | HTML/CSS | 기본 지면은 빠르고 선명한 단색으로 둔다. 실제 텍스트와 클릭 영역을 이미지에 넣지 않는다. |
| 종이 표면의 미세한 질감 | 기존 화면에는 없음 | 반복 가능한 약한 WebP | 새 `paper-fiber-subtle.webp`를 2·3단계에만 아주 낮은 대비로 겹친다. 24.8KB. 종이색과 글자 대비는 유지하며 과도한 누런색·얼룩을 피한다. |
| 구획선과 테두리 | 1px CSS 선, 월간 날짜 경계 | HTML/CSS | 반응형 날짜 칸에 정확히 맞춰야 하므로 CSS를 유지한다. 잡음이 있는 펜 자산으로 그리드 전체를 반복하지 않는다. 2·3단계의 제호 아래만 얇은 이중 인쇄선으로 바꾼다. 추가 파일 없음. |
| 형광펜 표시 | PNG를 마스크로만 사용하고 내부를 CSS 색으로 채움 | 투명 WebP 원본 획 + CSS 위치·불투명도 | 수정 제작한 `highlight-felt-02.webp`의 중앙 채움과 가장자리·양끝의 농도를 그대로 사용한다. 63.5KB. 같은 주의 한 계획에는 한 획만 올리고, 텍스트·날짜 버튼 위에 투명 클릭 요소를 만들지 않는다. 두 번째 예시는 색 필터를 쓴 **색 검토용**이며, 최종 5색 제작 방식은 시각 확인 뒤 확정한다. |
| 펜 밑줄 | CSS `clip-path` 다각형, 이후 긴 PNG의 축소 표시 | 외부 SVG | 새 `burgundy-ink-underline-flat.svg`를 선택한 숫자 한 곳에 56×16px로 쓴다. 시작과 끝의 높이 차이는 약 1.2px로 줄이고 두 번 겹친 작은 획을 넣었다. 422B이며 확대·축소해도 픽셀이 깨지지 않는다. 글자는 여전히 선택 가능하다. |
| 손으로 그린 동그라미·강조 | 기존 동그라미 PNG 3종, 검토 05에는 미사용 | 투명 WebP + 기존 변형 자산 | `blue-ink-circle-a.webp`를 선택 날짜 하나에만 시험 적용한다. 122.0KB. 다른 화면에는 a/b/c 변형을 의미 있는 강조에만 제한적으로 사용한다. 노란 선택 표시는 그대로 둔다. |
| 교정 기호와 작은 메모 표시 | 대표 화면에는 실제 교정 맥락 없음 | 필요한 경우 작은 SVG 또는 투명 WebP | 계획 숫자·날짜에 이유 없는 교정 표시를 붙이지 않는다. 향후 실제 편집/안내 문맥의 방향·체크 기호는 SVG, 잉크 질감 자체가 필요한 펜 흔적은 WebP로 검토한다. 현재 추가 자산 0개. |
| 페이지 번호·인장·라벨 | 제호와 `PLAN · DO · SEE`는 실제 텍스트, 인장은 없음 | HTML/CSS 텍스트 | 번호·인장을 지면 분위기만을 위해 새로 만들지 않는다. 필요한 발행 정보가 정해지면 실제 텍스트로 넣어 접근성과 번역 가능성을 유지한다. |
| 기능 아이콘 | 텍스트 `＋` 및 앱의 일부 SVG 선택 아이콘 | SVG 우선, 텍스트 버튼 유지 | 기능 아이콘은 확대·색상·포커스에 강한 SVG가 적합하다. 이 대표 시안에서는 기능 버튼을 교체하지 않아 기존 클릭·키보드 동작을 보존한다. 아이콘을 장식용 PNG로 대체하지 않는다. |
| 그림자·종이 겹침 | 기본 시안에는 없음 | 약한 CSS 그림자 | 2·3단계에서 지면 바깥에만 그림자를 준다. 콘텐츠 카드마다 종이를 겹치지 않는다. 1단계는 그림자 없음. 파일 비용 없음. |

## 기존 자산 판정과 이번 제작물

- **재사용**: `blue-ink-circle-a/b/c.png`의 서로 다른 펜 동그라미. 시안에서 쓰는 a형은 투명 WebP로 재인코딩했다. 원본 PNG는 보존했다.
- **수정**: `highlight-amber-01.png`의 길고 채워진 실루엣을 기준으로 `highlight-felt-02.png`를 새로 제작했다. 중앙에 흰 수채화 줄이 생긴 첫 새 시도는 채택하지 않았다. 최종 제작본은 가운데 색을 유지하고 표면 결·양끝 압력을 제한적으로 더했다. 사용 파일은 `highlight-felt-02.webp`; PNG 원본도 보존했다.
- **검토용 보관, UI에 직접 사용하지 않음**: `original-ink-circle.png`와 `reference-underline.png`는 참조 이미지다. `blue-ink-reference.png`도 참조용으로 남긴다. 긴 `burgundy-ink-underline.png`와 그 WebP 변환본은 작은 숫자 밑줄에는 부적합해 사용을 중단했다.
- **새 제작**: `paper-fiber-subtle.webp`(종이 재질 이미지에서 WebP 인코딩, 24.8KB), 짧은 숫자 밑줄용 `burgundy-ink-underline-flat.svg`(422B). 종이 질감은 기본 종이색 위에만 매우 약하게 겹친다.
- 새 형광펜과 종이 재질 이미지는 Codex 내장 **image_gen**으로 제작했다. 형광펜 최종 프롬프트 핵심은 “기존의 연속되고 거의 곧은 살구색 형광펜 실루엣을 보존하고, 중앙의 흰 줄 없이 채움을 유지하며, 가장자리 섬유결과 양끝 5%의 누름 자국만 약하게 더한다. 외부는 투명”이었다. 종이 프롬프트 핵심은 “깨끗하고 거의 보이지 않는 중성 아이보리 종이 섬유, 균일한 조명, 얼룩·그을림·찢김·글자 없음”이었다. WebP는 시각 내용 변경 없이 전달 크기만 줄인 인코딩이다.

## 같은 내용의 세 단계 비교

| 단계 | 더한 시각 요소 | 판단할 점 |
|---|---|---|
| 1. 기본 지면 | 단색 종이, 얇은 날짜·섹션 선, 세리프 제목과 산세리프 정보 | 장식 없이 계획명·날짜·완료 수가 읽히는 기준선. |
| 2. 종이·인쇄 깊이 | 매우 옅은 섬유결, 제호 아래 이중 인쇄선, 지면 외곽의 약한 그림자 | 분위기가 생기되 본문 대비와 월간 날짜선이 탁해지지 않는지. |
| 3. 펜·형광펜·교정 흔적 | 중심이 채워진 한 획/계획, 선택 날짜 한 곳의 펜 동그라미, 선택 숫자 한 곳의 펜 밑줄 | 실제 사람의 흔적으로 보이는지, 반복 자국이나 과잉 장식으로 시선이 흩어지지 않는지. 교정 기호는 의미가 없어 이번 화면에 추가하지 않음. |

세 단계는 동일한 HTML 내용과 월간 날짜 버튼·상세 스크롤·완료 계획 펼침을 공유한다. 단계 버튼은 `aria-pressed`로 상태를 알리고 키보드 포커스는 별도 윤곽선을 유지한다. 이미지 레이어는 `pointer-events:none`이며 자산은 `aria-hidden`인 장식에만 쓰고 실제 계획명과 숫자는 텍스트다.

## 데스크톱·모바일 및 확인 한계

- 데스크톱: 최대 1160px 지면에서 7열 달력, 계획 기간 한 획, 상세·근거의 원래 폭을 유지한다. 세 단계는 **같은 폭의 한 화면을 전환**하므로 좁아진 비교 카드 때문에 글자가 바뀌지 않는다.
- 모바일: 700px 이하에서는 지면 여백과 날짜 높이, 계획명 12px, 단계 선택 버튼을 한 열로 조정한다. 원본 2172px 획을 축소 표시하므로 래스터 확대가 아니라 축소가 일어나며 손실을 줄인다. 작은 7열에서 긴 계획명은 여전히 제한이 있으므로 실제 서비스에는 날짜별 상세를 유지해야 한다.
- 파일 크기: 이번 시안에서 새로 전송되는 종이·형광펜 파일은 합계 약 **88KB**. 선택 동그라미와 SVG 밑줄을 포함한 화면용 네 자산 합계는 약 **211KB**. 원본 PNG는 제작 보관용이며 시안 페이지는 WebP·SVG를 참조한다. WebP 미지원 환경 대체는 실제 서비스 이식 시 검토한다.
- 확인 완료: HTML의 스크립트 구문, 자산 경로 존재, PNG/WebP 크기와 투명 채널을 정적으로 확인했다. **실제 데스크톱·휴대폰 브라우저의 시각 결과는 아직 직접 확인되지 않았다.** 특히 색 필터가 선택한 ‘푸른 주석’ 5색과 정확히 일치하는지, 펜 동그라미가 작은 날짜 숫자에 거슬리지 않는지는 사용자 화면 검토가 필요하다. 시안의 색 비교 결과를 배포 완료나 접근성 검증 완료로 표시하지 않는다.

## 다른 페이지에 적용할 규칙

1. 인쇄 지면의 구조, 조작 요소, 구획선, 제목·본문은 코드와 실제 텍스트로 유지한다. 이미지에 텍스트를 굽지 않는다.
2. 배경 질감은 지면 한 겹에만 아주 약하게 사용한다. 입력창·버튼·통계 카드마다 질감을 반복하지 않는다.
3. 펜 자국은 의미 있는 강조에만 둔다. 한 화면의 동일 유형 자국은 드물게, 변형은 소수만 쓴다. 집계 숫자와 근거 이동, 선택 상태를 자국 하나에만 의존하지 않는다.
4. 날짜/시간 그리드와 기능 아이콘은 CSS/SVG로 둔다. 마우스·터치·키보드 영역은 장식 이미지와 별도이며 기존 폭을 줄이지 않는다.
5. 반응형에서 자산을 확대하기보다 큰 원본을 축소한다. 필요한 경우 모바일용 자산을 별도로 제작하고 실제 기기에서 획 끝, 날짜선, 본문 대비를 확인한다.
6. 대표 화면 승인 전 다른 페이지에 일괄 적용하지 않는다. T06 필수 집계·근거와 T07 인증·개인 자료 보호에 관한 정보는 디자인을 위해 삭제하거나 숨기지 않는다.
