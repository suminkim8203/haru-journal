# 다음 진행

요약: 승인 소스를 GitHub main에 통합했고 공개 배포·집계 근거·휴대폰 조회·제출문 사용자 확인을 완료했다. 운영 백업/복구 점검은 현재 PC의 Tailscale 로그인 복원 대기다.

1. 사용자가 기존 Tailscale 계정 로그인을 복원하면 NAS 관리 접속을 다시 확인한다.
2. 기존 백업·타이머·용량·자동 시작 설정을 읽고 중복 작업을 피한다. 운영 DB를 덮어쓰지 않고 백업을 만들어 격리 환경에서 복구한다.
3. VM 재부팅은 서비스 중단 범위와 예상 시간을 확인한 뒤 실행한다. 전체 플랫폼 복구 성공을 확인하기 전 완료로 기록하지 않는다.
4. [제출 자료](../submission/T06-SUBMISSION.md)는 확인한 주소/문장으로 준비했다. 외부 과제 제출 자체는 아직 실행하지 않았다.
