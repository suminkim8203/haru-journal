# T06 02.15 — 일간·계획의 행동 흐름 정리

한 줄 요약: 일간에서는 목록 선택 후 바로 기록·배치를 하고, 계획에서는 제목을 눌러 바로 수정하도록 불필요한 중간 단계를 줄였습니다.

## 현재 프로젝트에 실제 구현된 기능

사용자가 승인한 02.14의 돌아보기는 유지하고 다음 화면 묶음을 수정했습니다. 기준 파일은 `outputs/T06-flow-v2.15.html`, 동일 사본은 `work/T06-flow-v2.15.html`입니다.

### 일간

- 별도 ‘할 일 선택/바꾸기’ 선택창과 하단의 중복 ‘시간 미정’ 목록을 기본 동선에서 제거했습니다. 시간 미정 여부는 할 일 목록의 각 행에서 계속 표시합니다.
- 데스크톱의 왼쪽 목록, 모바일의 접이식 목록에 할 일 찾기를 넣었습니다. 제목·소속 계획·설명을 검색하며 작성 중인 입력이나 선택한 일, 저장 자료를 바꾸지 않습니다.
- 모바일과 접힌 데스크톱에서는 ‘할 일 목록’이 같은 화면의 목록을 펼치고 검색 입력으로 이동합니다. 별도의 두 번째 선택창을 만들지 않습니다.
- 선택한 할 일에 ‘기록 시작’, ‘시간 배치’, ‘실행 기록 입력’을 직접 제공합니다. 오늘만 타이머 시작, 지난 날짜는 수동 입력, 미래는 시간 배치를 제공합니다.
- 기존 예정 시간과 실행 기록은 건수와 함께 펼쳐 볼 수 있습니다. 배치 수정·삭제와 기록 정정은 유지합니다. 저장·종료 후 관련 내역이 펼쳐집니다.
- 다른 일을 기록하는 중에도 선택한 할 일을 일간에서 확인할 수 있게 했습니다. 갑자기 계획 화면으로 이동하지 않으며 진행 중 타이머의 대상은 바뀌지 않습니다.
- 완료 체크와 기록 종료는 기존처럼 별개입니다. 드래그 배치와 명시적 폼 입력을 모두 유지합니다.

### 계획

- 일반 할 일 제목을 누르면 수정 폼이 바로 열립니다. 제목 선택 후 ‘수정’을 다시 누르는 중간 행동 영역을 제거했습니다.
- 제목·마감일·예상 시간 등 기본 입력은 먼저 보이고, 예정 시간·실행 기록은 접어서 필요한 경우 펼칩니다.
- 완료 체크, 검색·필터·정렬, 루틴 규칙 목록·수정, 삭제·복원 정책을 유지합니다.
- ‘이전 계획 시안 보기’, ‘이전 휴지통 시안 보기’와 오래된 안내를 일반 계획 화면에서 제거했습니다. 비교 링크는 ‘시안 검토 도구’에서 사용할 수 있습니다.

## 구현하지 않은 기능 / 이번 범위 밖

- 보관함·설정 재구성, 회고의 보조 행동 정리, 돌아보기 시간 사용의 인라인 편집은 이번에 변경하지 않았습니다.
- 챌린지와 일상 루틴 누적 달성률은 추가하지 않았습니다.
- 실제 서버·DB·배포, 전체 JSON/PDF 내보내기는 여전히 미구현입니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스 추가 없이 기존 HTML 시안을 수정했습니다. 서비스 연결·설정 변경은 없습니다.

## 확인 순서

1. 일정에서 할 일을 선택하고 ‘시간 배치’ 또는 ‘실행 기록 입력’을 누릅니다. ‘시간 관리’를 먼저 열 필요가 없어야 합니다.
2. ‘예정 시간’과 ‘실행 기록’을 펼쳐 기존 내용을 확인합니다.
3. 계획에서 일반 할 일 제목을 누릅니다. 수정 폼이 바로 열리고 시간·기록은 접혀 있어야 합니다.
4. 모바일에서는 ‘할 일 목록’을 열어 선택한 뒤 작업 영역으로 돌아오는 흐름을 확인합니다.
