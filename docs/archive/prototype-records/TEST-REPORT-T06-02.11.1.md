# T06 02.11.1 점검 보고서

한 줄 요약: 기존 오류를 재현한 뒤 수정했으며, 총 49개 자동 점검이 통과했습니다. 실제 브라우저 UI 검증과는 구분합니다.

## 재현

02.11 스크립트에서 없는 두 버튼 ID 조회가 null을 반환하도록 대체 문서 환경을 보완했습니다. 별도 기간 선택 → 시작일 달력 열기 경로에서 `Cannot set properties of null (setting 'disabled')`가 발생했습니다.

이전 검사 환경은 없는 요소도 만들어 반환했으므로 이 연결 오류를 발견하지 못했습니다. 이번 검사에서는 해당 ID가 없다는 실제 HTML 조건을 반영했습니다. 전체 브라우저 DOM을 구현한 검사는 아닙니다.

## 수정 후 신규 점검

- 별도 반복 기간의 시작일·종료일 달력 열기와 닫기.
- 달력 날짜 선택 시 초안 반영 및 닫힘.
- 범위 밖 오늘·내일 비활성화, 일반 계획 달력을 열면 제한 상태 초기화.
- 실제 HTML의 버튼 속성과 잘못된 ID의 부재 확인.

기존 46개 점검과 신규 3개 점검, 총 49/49 통과. 실제 스크립트를 Node에서 실행했고 문서 객체와 저장소는 대체했습니다.

## 미검증

실제 브라우저 클릭, 모바일 위치와 레이아웃, 키보드 초점. 로컬 HTML 접근 제한을 우회하지 않았습니다.

반복 할 일 추가 → 이 할 일의 반복 기간 따로 설정 → 시작일 달력 → 날짜 선택 → 종료일 달력 → 날짜 선택 순서로 확인합니다.
