# T06 기획 결정 및 다음 검토

한 줄 요약: 현재는 화면 흐름을 검토하는 와이어프레임 단계이며, 루틴 계획 구조는 합의됐고 돌아보기는 시안 확인 후 결정합니다.

## 현재 프로젝트에 실제 구현된 기능

02.8의 계획/할 일 목록, 완료 체크박스, 시간·기록 전용 상세, 수동 실행 기록 추가·정정, 주간·월간 및 시간 선택을 기반으로 합니다. 02.9는 배치 팝업, 멈춤 유형 선택, 돌아보기 검토용 동작을 추가합니다. 실제 서비스 개발 완료를 뜻하지 않습니다.

## 구현되지 않은 기능과 결정 사항

### 확정: 일반 계획 / 루틴 계획

사용자는 2026-09-15 확인 질문에 `맞음: 일반 계획 / 루틴 계획 선택`이라고 답했습니다.

- 새 계획 생성 시 일반 계획 또는 루틴 계획을 선택합니다.
- 루틴 계획 안의 각 할 일마다 매일 반복할 기간·시각·예상 시간을 설정하는 구조입니다.
- 앞서 논의한 방향은 날짜별 할 일과 시간 배치를 구분하고, 반복 변경 시 `이 날짜만 / 이후 반복`의 적용 범위를 선택하는 것입니다. 이는 현재 02.9에 존재하는 버튼이 아니라 후속 루틴 설정·수정 화면에 둘 기능입니다.
- 과거 기록과 이미 시작·완료한 항목을 소급 변경하지 않는 방향을 유지합니다. 구체적인 예외 처리 규칙과 화면은 루틴 검토 단계에서 확인해야 합니다.
- 02.9에는 계획 유형 선택 및 반복 생성 UI를 아직 넣지 않았습니다.

### 돌아보기: 승인 전 검토안

1. 계획 결과: 무엇을 완료했고 무엇이 남았는지, 예상과 실제 작업은 어떻게 다른지 확인합니다. 선택한 마감일 범위의 할 일에 연결된 모든 종료 기록을 합산합니다.
2. 날짜별 시간 사용: 실제 활동 날짜에 작업·멈춤을 나눠 봅니다. 계획 결과와 합계 기준이 다르므로 같은 수치일 필요는 없습니다.
3. 회고: 다음 계획 전에 기억할 내용을 선택적으로 기록하고 책갈피 또는 계획 참고 메모로 보존합니다.

실제 화면을 본 뒤 동의/미동의/수정 사항을 받습니다. 아직 최종 승인으로 처리하지 않습니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스 연동 없음. 서버·DB·인증 기능은 이번 검토와 구분합니다.

## 확인이 필요한 불확실한 부분과 다음 순서

1. 02.9의 배치 팝업과 돌아보기 세 구역 검토.
2. 돌아보기 수정 사항 반영 및 화면 구조 합의.
3. 루틴 생성·수정·예외 처리 규칙과 와이어프레임 검토.
4. 전체 흐름 및 미결정 사항 점검, 잔여 개선 항목을 개발용 목록으로 정리.
5. 데이터 구조·권한·저장 정책과 기술 선행 조건 확정 후 실제 구현·테스트.

검토를 방해하는 오류나 집계 기준 오류는 지금 해결하고, 정렬·간격·장식 같은 경미한 개선은 목록으로 모아 개발 단계에서 처리할 수 있습니다.

이 작업에서 최신 파일과 결정 기록을 함께 관리하며 기획을 계속하는 것이 좋습니다. 기존 대화는 배경 자료로 보존하고, 양쪽에서 별도의 최신 결정을 동시에 만들지 않습니다.
