# PlanDoSee Diary — 페이지·이동 구조 v1.1

- 작성일: 2026-09-11
- 수정일: 2026-09-14
- 상태: 요구사항 v1.5와 일간 핵심 와이어프레임을 기준으로 정리한 화면 설계 기준선. 실제 앱 구현 목록이 아니다.

- 연결 문서: `requirements-v1.md`, `core-data-design-v1.md`

## 1. 구조 원칙

- 최초 화면은 오늘의 일간 일정이다.
- 시간 기록에 필요한 정보와 행동은 일간 상단의 통합 작업 영역에 모은다.
- 계획·실제·회고는 각각 독립 메뉴를 가지되 집계 숫자와 기록의 연결은 끊지 않는다.
- 데스크톱과 모바일의 기능은 같고, 모바일에서는 열 수 있는 영역을 한 번에 하나로 제한해 복잡도를 낮춘다.
- 링크를 아는 방문자는 로그인 없이 같은 자료를 보고 바꿀 수 있다. 이 공개 권한은 과제 6의 임시 조건이며 보안 기능이 아니다.
- 날짜 띠·주간·월간의 요일은 일요일부터 토요일까지 배치하고 월간은 1일부터 마지막 날까지 전체 날짜를 보여준다.

## 2. 전체 메뉴

| 1차 메뉴 | 시작 화면 | 핵심 목적 |
|---|---|---|
| 일정 | 오늘 일간 | 계획과 실제를 세로 시간축에서 비교하고 기록 시작·중단·종료 |
| 계획 | 계획 목록 | 계획·할 일·루틴과 원래 계획 이력 관리 |
| 돌아보기 | 기간 요약 | 숫자와 근거 기록 확인, 날짜별 회고 작성·조회, PDF 출력 |
| 보관함 | 책갈피 | 저장한 회고 문장과 보관한 계획 다시 보기 |
| 설정 | 관리 목록 | 중단 사유, 휴지통, JSON 백업 관리 |

## 4. 일간 핵심 상호작용

1. 타임라인의 작업 블록을 선택하면 상단 통합 작업 영역의 제목·상태·시간·행동이 즉시 바뀐다.
2. ‘상세 보기’를 누르면 같은 영역 바로 아래에서 계획·실제·막힘 정보가 펼쳐진다.
3. 기록 중이거나 잠시 멈춘 동안에는 다른 작업을 선택해 새 기록을 시작할 수 없다. 현재 기록을 먼저 마쳐야 하는 이유를 그 자리에서 보여준다.
4. ‘이번 기록 마치기’를 처음 누르면 그 시각을 종료 후보로 고정하고 가까운 확인 영역을 연다.
5. ‘계속 기록’은 후보를 버리고 이어가며, ‘기록 마치기’는 후보 시각으로 저장한다.
6. 기록 종료 후에도 할 일은 자동 완료되지 않는다. 완료·완료 취소는 작업 상세의 별도 행동이다.

## 5. 직접 링크와 돌아오기

- 집계 숫자 → 근거 목록 → 해당 날짜의 일간에서 작업 선택·상세 펼침 순으로 이동한다.
- 계획 이력·실행 기록 수정·회고 원문은 직접 링크로 다시 열 수 있어야 한다.
- 상세를 닫거나 뒤로 이동하면 이전 날짜·필터·정렬·스크롤 위치를 복원한다.
- 새로고침해도 선택한 날짜와 저장된 자료는 유지한다. 저장되지 않은 작성 중 입력의 보존 범위는 구현 설계에서 정한다.

## 6. 반응형 기준

- 데스크톱: 일간 타임라인과 통합 작업 영역을 같은 본문 흐름에 둔다. 별도의 상시 우측 상세 패널을 두지 않는다.
- 데스크톱: 계획·돌아보기·보관함·관리 화면은 본문 최대 폭을 약 940px로 제한해 긴 행을 줄인다. 일간은 계획·실제 비교를 위해 넓은 폭을 유지한다.
- 모바일: 날짜 이동 → 통합 작업 영역 → 타임라인 순서로 한 열에 배치한다. 상세 펼침 시 다른 부가 영역은 접는다.
- 모든 화면에서 핵심 저장·종료·삭제 행동은 고정된 위치 규칙을 사용하고, 색만으로 상태를 전달하지 않는다.

## 7. 다음 와이어프레임 묶음

아래 순서로 검토하면 데이터 관계와 과제 통과 기준을 가장 빨리 확인할 수 있다.

1. 계획 목록·상세·처음 계획 이력
2. 할 일 생성·편집·완료·취소·삭제와 검색·필터·정렬
3. 매일 루틴 생성과 ‘이 날짜만 / 이후 반복’ 변경
4. 실행 기록 수동 입력·정정과 중단 사유 관리
5. 돌아보기 집계 → 근거 목록 → 기록 상세 이동
6. 선택적 하루 회고 → 책갈피 → 다음 계획 전달
7. 휴지통·복원·영구 삭제
8. PDF 요약 미리보기와 JSON 백업

## 8. 현재 구현 상태

- 일간 핵심 흐름을 확인하는 인터랙티브 시안이 있다.
- 일간 날짜 띠·주간·월간의 날짜를 선택하면 해당 날짜의 일간으로 이동한다. 과거는 계획과 실제 기록, 미래는 계획과 루틴만 표시하며 오늘이 아닌 경우 `오늘로 돌아가기`를 제공하는 시안이 있다.
- 계획 목록·상세, 초안, 할 일 검색·상태 필터·정렬·완료 전환을 확인하는 계획 화면 상세 시안이 있다. 새 계획과 할 일 추가는 각각의 버튼 바로 아래에서, 계획 수정은 현재 계획 자리에서, 할 일 수정은 선택한 행 바로 아래에서 열린다. 삭제는 확인 대화상자를 사용한다.
- 돌아보기에는 계획·기간 범위, 계획 결과의 개수·시간 집계, 날짜별 시간 사용, 선택적 회고 목록이 분리되어 있다. 각 집계 숫자는 계산 규칙과 근거 목록을 열고 계획의 할 일 또는 해당 날짜의 실행 상세로 이동하며, 회고는 책갈피와 다음 계획 연결을 따로 선택하는 시안이 있다.
- 위 항목은 화면 동작을 검토하기 위한 시안이며 서버 저장 기능이 구현된 상태는 아니다.
- 보관함·설정은 구조 확인용 일부 화면만 있으며 위 페이지 목록의 완료 구현이 아니다.
- 서버 DB, 로그인, 실제 타이머 저장, PDF·JSON 생성, 삭제·복원은 현재 확인되지 않았다.
