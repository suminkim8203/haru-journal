# T06 02.14 — 돌아보기 계획 결과 정리

한 줄 요약: 일반 계획의 결과를 루틴과 분리하고, 할 일 제목을 강조한 근거 목록에서 실행 기록을 바로 펼쳐 읽도록 수정했습니다.

## 현재 프로젝트에 실제 구현된 기능

최신 검토 파일은 `outputs/T06-flow-v2.14.html`입니다. 동일한 작업 사본은 `work/T06-flow-v2.14.html`입니다. 실제 서버 앱이 아닌 브라우저 프로토타입입니다.

- ‘계획 결과’는 일반 계획에 속한 미삭제 일반 할 일을 대상으로 합니다. 루틴의 반복 규칙과 날짜별 발생 항목은 이 집계에 포함하지 않습니다.
- 대상 선택을 ‘모든 일반 계획’과 개별 일반 계획으로 명시했습니다. 선택한 일반 할 일 집합에 대해 계획 수·완료·지연·막힘·예상·실제·차이를 계산합니다.
- 루틴 날짜별 자료는 삭제하거나 합치지 않습니다. 날짜별 시간 사용은 루틴의 실제 작업 시간을 계속 포함합니다.
- 계획 결과의 필터는 날짜별 시간 사용·회고의 대상 계획 필터와 분리했습니다. 결과 구역에서 루틴이 숨겨져도 활동 구역에서는 해당 루틴을 선택할 수 있습니다.
- 근거 목록에서 할 일 제목은 18px/굵게, 보조 정보는 12px/기존 보조 글자색으로 표시합니다. 좁은 화면에서는 제목을 17px로 조정하고 보조 정보를 줄바꿈합니다.
- 완료 여부·예상 시간·실제 시간을 제목 아래 한 묶음으로 표시합니다.
- 특정 일반 계획 선택 시 대상 계획 이름을 행에서 생략합니다. 여러 일반 계획을 함께 볼 때만 계획 이름을 11px 보조 정보로 표시합니다.
- 각 행의 ‘할 일 보기’를 제거했습니다. 제목을 펼치면 같은 화면에서 마감일·설명·종료 실행 기록·막힘 메모·작업/멈춤 구간을 확인할 수 있습니다. 열람을 위해 계획 화면을 거치지 않습니다.
- 계획 결과의 혼합 완료율 표시를 제거하고, 루틴 건너뛰기 문구에 남아 있던 ‘완료율 제외’ 안내를 정리했습니다.
- 02.13 HTML과 내장 과거 비교 자료는 보존했습니다.

## 구현하지 않은 기능 / 이번 범위 밖

- 날짜별 시간 사용의 기존 ‘일간 상세’ 버튼과 그 수정 흐름은 이번에 바꾸지 않았습니다.
- 근거 안에서 기록을 수정하는 새 입력 화면은 추가하지 않았습니다. 이번 근거는 조회용이며 기존 수정 경로는 남아 있습니다.
- 일간의 선택 진입점, 시간 관리 단계, 계획의 이전 시안 링크, 보관함 및 설정 재구성은 후속 검토 대상입니다.
- 챌린지, 루틴 누적 진행률은 추가하지 않았습니다.
- 실제 서버·DB·배포, 전체 자료 내보내기 등의 생산 기능은 아직 없습니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스를 추가하지 않았습니다. 현재 시안의 집계·표시·이동 구조 변경입니다.

## 저장 및 과제 기준

02.14는 `t06.pds.flow0214.data`, `.ui`, `.clock` 키를 사용합니다. 처음 열 때 동일 출처에서 접근 가능한 02.13 자료가 있으면 우선 복사하며 이전 키는 변경하지 않습니다. 파일 URL의 브라우저 저장 출처 차이 때문에 사용자의 기존 자료가 자동으로 옮겨진다고 보장하지 않습니다. 기존 02.13 파일과 브라우저 자료를 초기화하지 않았습니다.

일반 계획의 C28~C32 공식과 C83의 근거 접근은 유지하면서, 계획 결과의 표시 범위를 일반 계획으로 변경했습니다. 기존의 일반/루틴 혼합 집계 정책을 이 구역에서 대체합니다. 과제 통과나 실제 DB 검증 완료를 뜻하지 않습니다. 전체 요건 통합 문서와 실제 데이터 계약은 여전히 후속 작업입니다.

## 확인 방법

1. 02.14를 열고 ‘돌아보기’ → ‘계획한 할 일’을 선택합니다.
2. 제목과 보조 정보의 위계, 각 행의 ‘할 일 보기’가 없는 것을 확인합니다.
3. 제목을 펼쳐 화면 이동 없이 기록을 읽고, 특정 계획을 선택하면 행의 계획 이름이 사라지는지 확인합니다.
4. 루틴을 추가하더라도 일반 계획 결과 수는 늘지 않고, 실제로 기록한 루틴 시간은 날짜별 시간 사용에 남아야 합니다.

## 확인이 필요한 부분

코드와 대체 DOM 검사는 완료했으나 실제 브라우저의 시각 배치·포커스·터치·모바일 조작은 확인하지 못했습니다. 실제 사용 자료와 64개 표시의 구성도 확인하지 않았습니다. 테스트는 분리된 예시 자료만 사용했습니다.
