# 과제 7 — 제출 증거 사전 준비

한 줄 요약: 계획과 빈 기록 양식은 미리 만들 수 있지만, 잠긴 앱의 실제 사용과 요청/응답 증거는 실행 이후에만 작성합니다.

## 제공받은 범위

이번에 받은 것은 과제 7 주제 설명입니다. 가입·로그인과 소유권 보호, 선택 이유·소스 변경 위치·직접 확인·미해결 한계, 비밀값을 가린 실제 요청/응답, 잠긴 앱 5일 실제 사용, 3일차 전 계획 규칙 한 가지 변경이 명시돼 있습니다. 전문의 통과 기준이나 5일 연속 여부·하루 최소 사용 시간은 아직 확인되지 않았습니다.

## 지금 준비한 것

- five-day-plan-draft.json: 사용자가 진행 중인 T06 제작을 소재로 한 일반 계획 1개·할 일 5개. 날짜 미지정, 실행 0건, 완료 0건. 추후 DB 변환용이며 아직 저장된 앱 자료가 아닙니다.
- 아래 T07 사용·증거 양식. 과제 6에서 공개했던 자료가 로그인 도입만으로 과거까지 비공개가 된다고 주장하지 않습니다.

## 잠긴 앱이 준비된 뒤의 5일 사용안

하루 종일 사용해야 한다는 조건은 제공된 설명에 없습니다. 매일 실제로 하는 짧은 작업을 기록하는 방식이 가능할지 전문을 확인합니다. 사용하지 않은 날짜를 채워 넣거나 기록 시각을 소급 조작하지 않습니다.

| 시점 | 실제로 할 일 | 남길 증거 |
|---|---|---|
| 1일차 | 본인 계획과 할 일을 넣고 실제 작업 기록 | 실제 날짜, 계획/할 일 ID, 실제 시작·종료, 최초 규칙 |
| 2일차 | 같은 앱으로 작업하고 예상/실제 확인 | 실행 ID, 차이, 실제로 느낀 개선점 |
| 3일차 진입 전 | 계획 규칙 하나만 변경 | 변경 전/후 문장, 실제 변경 시각, 이유. 원래 계획 이력 보존 |
| 3일차 | 바뀐 규칙으로 실제 작업 | 적용된 할 일과 실제 결과 |
| 4일차 | 같은 규칙 유지하며 사용 | 실제 기록과 막힘이 있었다면 사실만 기재 |
| 5일차 | 실제 사용 후 전후 비교 | 근거 기록과 회고, 과장하지 않은 결론 |

규칙 변경 후보: ‘오늘의 최우선 할 일을 최대 3개 선택’에서 ‘최대 1개 선택’으로 변경. 아직 적용하거나 변경했다고 기록하지 않습니다. 사용자의 실제 습관에 맞으면 채택합니다.

## 인증과 권한은 별개로 기록

- 회원가입: 계정 생성 요청과 결과.
- 로그인: 자격 증명 검증 및 세션 생성 결과.
- 소유권 보호: 비로그인 요청, 본인 요청, 다른 사용자 요청을 각각 검증. 로그인 성공 자체가 다른 사람 자료 차단의 증거는 아닙니다.
- 초대, 이메일 확인, 계정 활성화, 최초 비밀번호 설정, 변경, 재설정은 선택한 방식 및 과제 전문을 확인해 필요 여부를 각각 정합니다. 모두 구현됐다고 가정하지 않습니다.

## 실제 확인 뒤 채울 요청/응답 기록 양식

- 검사 ID / 실제 검사 시각 / 검사한 소스 버전:
- 기능 및 연결된 실제 파일·변경 위치:
- 실행 주체: 비로그인 / 본인 / 다른 사용자:
- 요청 방식·경로·가린 입력:
- 기대 결과:
- 실제 상태 코드·가린 응답:
- 자료 변경 유무 확인:
- 판정: 통과 / 실패 / 미검증:
- 미해결 한계:

실제 결과를 보기 전 401/403/404 등의 응답을 미리 성공 증거로 작성하지 않습니다. 소유권 노출 방지를 위해 의도된 응답이 다른 경우 기대 정책과 비교합니다. 비밀번호·토큰·쿠키·비밀키 원문은 첨부하지 않습니다. 심사용 실제 계정 비밀번호를 제출하지 않습니다.

## 이후 작성할 제출 자료

구현 선택과 이유 → 실제 소스 변경 경로 → 가린 요청/응답으로 접근 차단 검증 → 못 막은 사항 → 실제 5일 기록 → 3일차 전 변경한 한 규칙과 근거 비교.

5일을 확보하지 못하면 완수했다고 꾸미는 대신 미충족 상태와 실제 사용 일수를 명시하고 제출 일정·인정 조건을 확인합니다. T06 제작의 실제 기록을 T07의 잠긴 앱 사용 기록으로 재명명하지 않습니다.
