# T06 02.10 변경 기록

한 줄 요약: 02.9를 보존하고 일반/루틴 계획, 매일 반복, 날짜별 수정과 반복 예외를 검토할 수 있는 HTML 시안을 추가했습니다.

## 현재 프로젝트에 실제 구현된 기능

아래는 브라우저 상태 변화만 구현한 프로토타입 기능입니다.

- 새 계획 생성 시 일반 계획 / 루틴 계획 선택. 루틴 계획 저장 후 첫 반복 할 일 입력으로 연결합니다.
- 반복 할 일마다 계획 기간 안의 시작일·종료일, 예상 시간, 우선순위 설정.
- 시각 없이 반복: 날짜별 할 일만 생성. 정해진 시각에 반복: 날짜별 할 일과 예상 시간 길이의 예정 배치를 생성.
- 계획·할 일 목록·일간 상세·일간 타임라인에 반복 표시. 월간에도 루틴 개수 표시.
- 일간 목록은 루틴의 선택 날짜 항목만 표시. 기존 일반 할 일은 이전 방식대로 전체 표시.
- 날짜별 완료 독립. 미완료 자동 이월 없음.
- 반복 할 일 수정은 내용 입력 → 적용 범위 확인 순서. 기본은 이 날짜만. 이후 반복 선택 시 수정·추가·기간 제외·보존 수와 해당 날짜 확인.
- 이후 변경에서 지난 날짜·완료·실행 기록이 있는 날짜·개별 수정·건너뛰기·중단 항목 보존.
- 이 날짜만 수정하거나 명시적 시간 배치/드래그로 배치를 바꾸면 개별 수정으로 기록합니다.
- 날짜별 예정 배치 변경 시 기존 예정 배치를 보존 표시하고 새 배치로 교체합니다. 실제 실행 기록은 건드리지 않습니다.
- 반복 생성·수정에서 기존 예정과 겹치면 확인 후 반영. 저장 실패 시 초안 유지.
- 날짜별 건너뛰기: 확인 후 해당 날짜 예정 배치 제외. 다른 날짜는 유지.
- 이후 반복 중단: 적용 대상 예정 배치와 할 일을 진행 대상에서 제외하되 원래 자료와 실행 기록은 보존.
- 돌아보기에서 건너뛰기·중단 개수와 제외 항목 확인. 완료율과 지연 대상에서 제외.
- 7일간의 스트레칭(고정 시각)·독서(시각 미정) 예시 추가 버튼.

## 구현되지 않은 기능

- 요일별·주간·월간 반복, 무기한 반복, 반복 재개, 건너뛰기 취소 UI.
- 일반/루틴 계획 유형의 생성 후 전환.
- 루틴 계획 안의 일회성 할 일 생성 UI.
- 실제 서버·DB·계정·권한·백그라운드 일정 생성.
- 시안 자료의 이전 버전에서 자동 이관.

## 서비스가 지원하지만 현재 사용하지 않는 기능

연결된 서버 서비스가 없습니다. 일반적인 서비스 기능을 현재 구현으로 간주하지 않습니다.

## 확인이 필요한 부분

- 실제 데스크톱/모바일 UI 조작은 미검증입니다. 로직 검사 결과와 구분해야 합니다.
- 시안 보호를 위해 한 번에 최대 366일만 생성합니다. 이는 제품 정책 확정이 아닙니다.
- 완료하거나 실행 기록이 있는 날짜는 건너뛰기를 막습니다. 기존 기록 보존을 위한 시안 동작이며, 부분 실행 후 건너뛰기가 필요한지는 후속 검토 항목입니다.
- 일괄 수정은 대상 날짜의 모든 예정 배치를 입력한 시각·예상 시간으로 교체합니다. 복수 배치 유지/변경의 세부 UX는 검토 대상입니다.
- 기간 축소로 제외된 날짜와 중단 날짜는 자동으로 복원하지 않습니다. 재개/복원 정책은 미정입니다.
