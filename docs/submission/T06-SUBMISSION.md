# T06 제출 자료

> 2026-09-21 자료 변경: 예시를 정리하고 실제 대화에 근거한 사후 정리 자료를 반영했다. 현재 종료 실행은 2건이며 C80 충족 전이다. [현행 자료와 남은 조건](ACTUAL-ACTIVITY-2026-09-21.md).

요약: 공개 결과물과 소스, 확인 방법을 정리했다. 사용자 판단 문장은 대화에 근거하며 2026-09-21 본인 동의를 받았다.

## 주소

- 결과물: https://haruleaf.com/
- 소스: https://github.com/suminkim8203/haru-journal

## 짧은 확인 방법 — 4줄

1. 어디로 가나요: 결과물 주소에서 돌아보기 → 계획 결과로 이동합니다.
2. 무엇을 하나요: Haru — 6번 과제 구현과 제출 준비 계획을 선택 → 완료 숫자 선택 → 근거 할 일을 확인합니다.
3. 통과 기준: 완료 5와 근거 할 일 5개가 일치하고 새로고침 후에도 유지됩니다. 이 계획의 실행 시각은 미확인이며, 기존 타이머 2건은 별도 계획에 보존돼 있습니다.
4. 안 될 때: 연결·입력 오류 안내와 최신 자료 확인이 표시됩니다. 입력을 확인하고 저장 결과가 불명확하면 이전 저장 결과 확인으로 재확인합니다.

## AI와 내 판단 — 본인 확인 완료 3줄

1. AI에게 맡긴 일: 화면·DB 구현, 과제 기준 대조, 자동 검사와 배포·문서 정리를 맡겼습니다.
2. 내가 직접 판단한 일: 신문과 개인 기록장 분위기, 서체의 역할, 제호 위치, 단상·회고 구분과 일정 화면의 사용 흐름을 직접 결정했습니다.
3. AI 제안을 따르지 않은 일: 루틴 누적 진행률과 불필요한 이동·중복 기록 표시를 줄였으며, 승인 시안과 다른 구현은 그대로 수용하지 않고 원래 디자인으로 복원하도록 했습니다.

## 자료/조건 구분

현재 공개 자료는 사용자 검토 활동의 사후 정리이며 당시 세운 계획이나 확인되지 않은 시간을 새로 지어내지 않았다. 예시 자료는 휴지통에 보존했다. 종료 실행 3개 이상 기준은 아직 충족하지 못했으며, 실제 자료 조건이 면제됐다고 주장하지 않는다.
