# T06 02.16 — 버튼 구분과 주간 목록 가독성

한 줄 요약: ‘계획 배치’ 명칭과 두 묶음의 행동 버튼을 적용하고, 주간의 예정·실제를 제목 중심 점 목록으로 정리했습니다.

## 현재 프로젝트에 실제 구현된 기능

- `outputs/T06-flow-v2.16.html`이 최신 시안이고 `work/`의 동일 이름 파일과 내용이 같습니다.
- ‘시간 배치’ 버튼을 ‘계획 배치’로 변경했습니다. ‘실행 기록 입력’은 유지했습니다. 배치 확인·수정 제목도 같은 용어로 맞추고, 폼에 ‘선택한 할 일을 시간표에 배치합니다.’를 표시합니다.
- 오늘의 ‘기록 시작’은 윗줄의 주요 행동으로, ‘계획 배치·실행 기록 입력’은 아래 입력 행동 묶음으로 표시합니다. 사이 여백은 기본 20px, 좁은 화면 18px입니다. 버튼의 실제 동작과 오늘/과거/미래 조건은 유지합니다.
- 주간 항목을 실제 ul/li 점 목록으로 변경했습니다. 항목 간 점선은 제거하고 여백으로 구분합니다.
- 표시 순서는 제목 → 시작·종료 시각 및 실제 작업 시간 → 우선순위와 완료 표시입니다. 마감 항목의 완료·미완료·지연 표시도 유지합니다.
- 예정·실제 구역 제목을 더 선명하게 표시합니다. 실제 구역에 옅은 배경을 적용하고 구역 간 여백을 늘렸습니다.
- 제목은 줄바꿈하며 자르지 않습니다. 보조 글자는 기본 11px, 모바일 12px입니다. 380px 이하에서는 구역을 세로로 쌓습니다.
- 예정과 실제에 같은 할 일이 각각 나타나는 것은 비교용으로 유지합니다. 집계 대상·값·자료 구조는 바꾸지 않습니다.

## 구현하지 않은 기능 / 이번 범위 밖

새 기능이나 챌린지는 추가하지 않았습니다. 서버·DB·배포, 보관함·설정 및 회고 보조 동작의 남은 정리는 별도 작업입니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스 변경은 없습니다. 기존 브라우저 프로토타입의 표시와 배치만 수정했습니다.

## 검증과 보존

- 변경 관련 검사 10개와 기존 회귀 76개, 총 86개가 02.16 대상으로 통과했습니다.
- 주간 합계·항목 수가 02.15와 같고, 자정 넘김·멈춤 제외·미종료 기록 제외·일간 이동을 확인했습니다.
- 02.15와 비교용 과거 자료는 보존했습니다. 새 저장 키는 `t06.pds.flow0216.data`, `.ui`, `.clock`이며 접근 가능한 02.15 자료를 처음 한 번 복사합니다.

## 확인이 필요한 부분

실제 브라우저의 글자 크기·여백·좁은 화면 줄바꿈·키보드 포커스·터치 조작은 아직 확인되지 않았습니다. 사용자 저장 자료의 자동 복원 여부도 확인되지 않았습니다. 이전 파일의 사용자 자료를 읽거나 초기화하지 않았습니다.

확인 순서: 일간에서 할 일 선택 → 버튼 두 묶음 확인 → 주간에서 예정/실제 구분과 제목·시각·우선순위 확인.
