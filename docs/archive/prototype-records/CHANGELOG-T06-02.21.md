# 02.21 변경과 다음 검토

확정 용어: 단상 / 회고. 현재 검토 파일: T06-flow-v2.21.html.

- 막힘 지표와 근거를 제거했습니다. 실행 시간·휴식·중단 기록은 보존합니다.
- 기존 실행 기록 note를 복사하지 않고 단상 목록에서 직접 참조합니다. 새 단상과 지난 기록의 글을 한 곳에서 확인하며, 일반 상세에서는 예정 이력 아래/실행 이력 위에 놓입니다. 종료 화면의 별도 막힘 입력은 제거했습니다.
- 과거 실행 기록 단상 수정은 기존 기록 수정 폼으로 연결합니다. 삭제는 noteDeleted 표시로 단상만 휴지통에 보내며 시간을 바꾸지 않습니다. 원문과 이미 저장한 회고는 독립적입니다.
- 회고 북마크는 회고 ID에 연결된 bookmarked 상태입니다. 기존 스냅샷 북마크 자료는 보존하고 최초 상태를 유도합니다. 해제 가능하며 회고 편집 뒤에도 북마크 상태를 유지합니다.
- 보관함은 회고 모음/휴지통 두 탭입니다. 별도 북마크 탭을 없애고 회고 모음의 전체/북마크한 회고 필터로 통합했습니다.
- 보관함 탭 왼쪽 정렬, 낮은 높이, 위쪽 선택선. 수정/삭제는 가로 팝오버이며 헤더 레이아웃을 밀지 않는 위치 지정 방식입니다.
- 작업명 후보 ‘하루의 여백’을 헤더에 적용했습니다. 최종 이름 승인은 아직입니다. 왼쪽: 오늘 할 일을 적고 / 보낸 시간을 남깁니다. 오른쪽: 틈틈이 생각을 적고 / 하루를 돌아봅니다. 이름 사용 가능성·상표·도메인은 확인하지 않았습니다.

검사: 신규 8 + 주간 10 + 루틴 14 + 기존 휴지통 7 = 39개 로직 검사 통과. 실제 DOM을 대체한 검사이며 실제 브라우저의 메뉴 배치/폰트/모바일 시각 검증은 하지 못했습니다. 02.20의 막힘 집계 및 스냅샷 북마크를 요구하는 검사는 이번에 폐기된 요구사항이므로 통과 검사로 주장하지 않습니다.

독립 flow0221 저장 키를 쓰며 접근 가능한 flow0220을 최초 복사합니다. 이전 파일/자료는 덮어쓰지 않습니다. 실제 file URL 저장소 공유는 미확인입니다.

다음 확인: 단상 입력 위치와 과거 글 조회, 회고 북마크 필터, 보관함/⋯ 메뉴의 가독성, 작업명 후보와 양옆 문구. 이후 확정 화면을 기준으로 실제 데이터 계약과 기술 구성 정리. 서버·DB·배포는 아직 구현하지 않았습니다.
