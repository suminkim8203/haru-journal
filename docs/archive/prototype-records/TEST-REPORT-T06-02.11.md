# T06 02.11 점검 보고서

한 줄 요약: 기존 회귀 점검 39개와 새 점검 7개, 총 46개 자동 점검이 통과했습니다. 실제 브라우저 UI 검증은 아닙니다.

## 방법

결과 HTML의 실제 JavaScript를 Node 독립 실행 환경에서 실행했습니다. 문서 요소와 저장소는 대체 객체입니다. CSS 관련 검사는 선언 및 마크업 검사이며 실제 계산된 레이아웃을 검사한 것이 아닙니다. 검사 전용 내부 접근은 메모리에만 추가했습니다.

## 신규 7개

1. 새 루틴에서 계획 기간 기본 선택, 날짜 입력 및 별도 계획 날짜 단축 버튼 미노출, 실제 생성 기간 일치.
2. 별도 기간 선택 시에만 날짜 입력 표시, 별도 날짜 보존, 다시 기본 선택하면 잘못된 날짜 초안 제거. 체크박스 input→change 순서도 대체 이벤트로 실행.
3. 루틴 100개×30일=날짜별 자료 3,000개를 만든 상태에서 계획 화면은 루틴 20줄만 출력. 날짜별 행·완료 체크박스 없음. 검색·페이지 이동 확인.
4. 선택한 루틴의 이력만 기본 7개 출력. 전체 30일 조회 시 20개/10개로 분리. 닫아도 자료 변경 없음.
5. 반복 규칙 수정에서 날짜별 완료 기능과 이 날짜만 선택을 노출하지 않음. 이후 반복 확인 및 모의 실패 후 재시도.
6. 이력의 일간 보기에서 정확한 날짜/항목 선택. 일간에는 날짜당 루틴 100개만 나타나며 전체 3,000개가 나오지 않음.
7. 돌아보기 근거의 할 일 보기는 관련된 날짜 하나의 이력으로 연결.

## 회귀 범위

기간 오류, 직접 입력 날짜, 실행 기록 정정과 이력, 멈춤 구분, 날짜별 집계, 배치 확인, 반복 예외 보존·중단·건너뛰기, 회고와 책갈피, 저장 실패, 이전 버전 저장 자료의 비파괴 복사 등.

이전 기간 입력 검사는 새 기본값에 맞춰 별도 기간을 선택한 상태에서 실행했습니다.

## 미검증

실제 브라우저의 클릭·드래그·초점, 모바일 시각 배치·스크롤, 브라우저별 로컬 저장소 접근. 로컬 파일 접근 제한을 우회하지 않았습니다. 자동 점검 통과를 사용자 조작 검증 완료로 해석하지 않습니다.
