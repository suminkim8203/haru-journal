# T07 작업 RULE — 요구사항 요약

이 문서는 사용자가 2026-09-21 제공한 과제 지시문을 작업용으로 요약한 것이다. 원문 전문이 아니다. 현재 인증 작업에는 T07 기준을 적용한다. T06의 로그인 없는 공개 조건은 T06 제출 보관본에만 유지한다. T06 더미 허용 예외를 T07 실제 5일 기록에 확대하지 않는다.

## 필수 기준

- C91–93: 방식·이름·실제 버전·대안과 미선택 이유.
- C94–100: 가입/로그인/로그아웃, 미인증 자료 화면은 로그인 화면, 중복 가입 방지, 없는 아이디/틀린 비밀번호 동일 안내, T06 자료를 본인 계정에 이전.
- C101–107: bcrypt/argon2/scrypt/PBKDF2 방식·이유, 저장 해시 증거, 동일 비밀번호의 다른 해시, 로그·응답·화면에 비밀번호 원문 미노출, 널리 쓰는 구현에 위임 여부 명시.
- C108–115: 세션/토큰 방식, 동일 URL/메서드/인증값으로 로그아웃 전 성공·후 거절, 만료, URL에 세션/토큰 없음, 비밀키 미노출, 비밀번호 변경/로그아웃 후 이전 값 거절, 증거 인증값 마스킹.
- C116–126: 두 계정 자료, A→B/B→A 읽기·수정·삭제 모두 403/404, 거절 전후 상대 자료 수/내용/신규 자료 불변, URL·헤더·본문 소유자 위조, 미인증 직접 요청 거절, 목록 분리, 관련 소스 위치.
- C127–131: 설명서 6항목(무엇/왜/어디/거절 증거/AI와 나/미해결 위험), 가입·로그인·로그아웃·조회 경로, 5가지 검증의 성공/거절 쌍, 실제 미해결 위험과 이유, 비밀 마스킹. 5가지 묶음은 계획서상의 해석이며 모든 개별 기준도 독립적으로 점검한다.
- C04–08: 1일차 질문·지표·단위·계산 규칙 고정, Asia/Seoul의 서로 다른 실제 날짜 정확히 5일을 실험 대상으로 지정. 계정의 기존 다른 날짜 기록을 삭제하라는 뜻으로 해석하지 않는다.
- C23–27: 누락·중복·이상값·반올림·주 시작 요일 명시.
- C09–15: 2일차 완료 뒤 3일차 시작 전 규칙 하나만 변경, 시각·이유·1/2일차 정확한 참조, 동일 지표·단위·계산으로 비교.
- C132–134: 5일 합계/평균 수작업 대조, 본인 전체 자료 한 파일 내보내기, 계정 삭제 시 자료 삭제/삭제 안내.
- C03/C01: 미로그인 첫 화면은 로그인 화면이며 심사자가 별도 가입 없이 그 화면/소스에 접근. 개인 기록은 비공개.
- C39/C40/C46: 확인 4줄, AI와 본인 판단 3줄, 공개 자료에 비밀 없음.
- C77/C78: 이어 쓴 최종 T06 명시, 고정 T06 commit이 T07 이력 조상.

## 증거·실행 원칙

로그아웃은 브라우저 값 삭제만으로 완료 처리하지 않는다. UI 은닉만으로 자료 보호를 주장하지 않는다. 계정/키/메일 발송·자료 이전·공개 서비스 전환은 실제 검증 단계에서 수행하며 현재 문서화만으로 실행하지 않는다. 과제 증거용 비밀번호 해시는 폐기 가능한 검증 계정을 사용하고 실제 계정 비밀번호/토큰/비밀키는 제출하지 않는다. 실제 5일 기록은 인증된 앱에서 수행하며 소급·가상 기록으로 대체하지 않는다.
