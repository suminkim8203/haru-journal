# T06 02.9 테스트 보고서

한 줄 요약: 실제 HTML 안의 JavaScript를 실행하는 로직 검사 17개가 통과했습니다. 실제 브라우저 클릭·드래그·모바일 화면 검증은 미완료입니다.

## 수행한 검증

2026-09-15. Node 실행 환경에서 HTML의 실제 스크립트를 추출해 실행했습니다. 문서 요소와 브라우저 저장소를 대체한 검사 환경이므로 사용자 화면 테스트와 다릅니다. 검사 전용 내부 접근 지점은 메모리에만 추가했으며 결과 HTML에는 넣지 않았습니다.

1. 실제 스크립트 구문 및 초기화, 02.9 버전.
2. 멈춤 25분을 휴식으로 바꿔도 작업 49분 유지.
3. 실행 기록 정정 시 이전 구간 유형 보존.
4. 역전·중첩된 멈춤 구간 검증.
5. 자정 통과 기록의 날짜별 분할 및 진행 중 기록 제외.
6. 날짜별 시간 사용의 계획 필터.
7. 15분 위치 맞춤과 확인 전 배치 미저장, 팝업 내용 생성.
8. 배치 취소 시 변경 없음 및 팝업 닫힘 상태.
9. 겹침 확인 필수, 저장 실패 시 초안 유지, 재시도·중복 호출에서 배치 한 건 생성.
10. 돌아보기 세 구역 및 일간 마무리 화면 내용 생성.
11. 기록 상세 이동 후 돌아오기 시 구역·계획·주·펼친 날짜 복원.
12. 빈 회고로 마무리하되 할 일 완료 상태는 불변.
13. 날짜 중복 회고 거절 및 입력 유지.
14. 회고 원문 수정 후 책갈피·계획 메모의 발췌 보존 및 수정 이력.
15. 열린 기록이 있으면 하루 마무리 거절 및 입력 유지.
16. 주간·월간 일정 화면 내용 생성.
17. 대체 이벤트로 실제 드래그 처리 함수를 실행해 예상 시간 초안 생성 및 미저장 확인, 터치형 포인터의 드래그 시작 제한 확인.

결과: 17/17 통과. 이 숫자는 실제 사용자 조작 테스트 통과 수가 아닙니다.

## 미검증 항목

브라우저 도구가 로컬 HTML 접근을 차단했습니다. 다른 경로로 제한을 우회하지 않았습니다.

- 실제 마우스 드래그·드롭과 가장자리 자동 스크롤의 자연스러움.
- 팝업 중앙 위치, 화면 잘림, 겹침 경고와 버튼의 시각적 접근성.
- 실제 Escape 처리·초점 가두기·원래 할 일로 초점 복원.
- 모바일 폭의 접이식 목록·팝업·기록 정정 화면, 터치 조작.
- 시간 선택 팝업과 새 팝업 사이의 실제 상호작용 회귀 검사.
- 실제 브라우저의 새로고침 후 저장 자료 복원 및 여러 탭 충돌.

## 직접 검토 순서

1. 02.9를 열고 일간 왼쪽 할 일을 예정 타임라인으로 드래그합니다. 화면 아래로 이동하지 않고 중앙 확인 창이 떠야 합니다.
2. 취소는 배치를 만들지 않아야 합니다. 다시 드래그해 배치를 누르면 예정 블록만 생기고 실행 기록은 시작하지 않아야 합니다.
3. 기존 블록과 겹치게 놓으면 확인 체크 전에는 배치할 수 없어야 합니다.
4. `돌아보기 → 계획 결과` 숫자를 눌러 근거를 보고 일간 상세에서 돌아옵니다.
5. `날짜별 시간 사용`에서 날짜를 펼치고, `회고`에서 문장을 책갈피에 저장하거나 계획에 붙입니다.
6. 회고 원문을 수정한 후 계획의 `회고에서 가져온 메모`에 붙인 문장이 유지되는지 확인합니다.
7. 일간의 하루 마무리를 회고 없이 진행해도 미완료 체크박스는 그대로여야 합니다.
8. 좁은 화면에서는 드래그 대신 할 일 선택 → 시간 관리 → 시간 추가 배치를 사용합니다.

## 회귀 검증 범위

02.7/02.8의 보존 해시를 확인했습니다. 기존 기능 전체에 대한 실제 브라우저 회귀 검사는 아직 완료하지 않았으므로 개발 착수 전 별도 확인이 필요합니다. 이전 02.8 보고서의 소스 구조 점검 또한 실제 클릭·드래그 검증으로 간주하면 안 됩니다.
