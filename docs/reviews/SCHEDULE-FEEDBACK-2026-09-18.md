## 과제 기준과 보완

제안된 표시/이동 정리는 필수 기준과 직접 충돌하지 않는다. 실제 실행 기록·휴식/중단 구간·막힌 이유·집계/근거·다음 계획 개선점 전달·공개 안내를 삭제하지 않는다. 짧은 색인 삭제 시 작은 블록의 접근성, 구간 접힘 삭제 시 기록 삭제 기능 보존이 필요하다. 완료된 할 일의 배치/기록 시작 제한은 유지한다. 월간 할 일은 배치/마감 기준으로 중복 제거하고 날짜가 없는 할 일을 임의 날짜에 넣지 않는다. 날짜 미정 표시 범위는 아직 확정하지 않는다.

추천 순서: 상세/선택 연결 및 계획명·활성 기록 → 툴팁·색인·구간 접힘·새벽 버튼·귀환 제거 → 월간 간략 확인. 사용자 검토 전 구현 완료로 기록하지 않는다.
