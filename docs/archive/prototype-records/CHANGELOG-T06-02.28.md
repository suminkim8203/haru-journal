# 02.28 보관함 메뉴 통일

- 회고 모음/휴지통 메뉴를 돌아보기의 review-tabs 형식으로 통일.
- 같은 높이·간격·하단 활성선·모바일 글자 크기. 기존 library-index 상단 강조선 제거.
- 선택 동작/자료/서체는 유지. inline JavaScript 구문 검사 통과.
- 계획/보관함 폭은 아직 변경하지 않았습니다. 돌아보기와 같은 940px 중앙 정렬을 제안한 상태입니다.
- 실제 브라우저 렌더링 검사는 미완료입니다.
