# T06 02.8 검토 팩

한 줄 요약: `T06-flow-v2.8.html`을 브라우저에서 열어 일정·일간의 계획별 할 일 목록과 drag & drop 시간 배치 흐름을 검토합니다.

## 포함 파일

- `T06-flow-v2.8.html`: 최신 검토용 시안
- `T06-flow-v2.7.html`: 변경하지 않은 기준 시안
- `T06-handoff-originals-2026-09-15.zip`: 이전 작업에서 전달된 요구사항·페이지 맵·데이터 설계·비교 시안 원본 묶음
- `CHANGELOG-T06-02.8.md`: 변경 범위와 미구현 범위
- `TEST-REPORT-T06-02.8.md`: 자동 검증 결과와 수동 확인 항목

## 우선 검토 흐름

1. 일정 → 일간에서 왼쪽 계획 폴더와 할 일 목록을 확인합니다.
2. 할 일 제목을 선택하고 `기록 시작`, `시간 관리`의 역할 분리를 확인합니다.
3. 완료는 목록 체크박스에서만 변경합니다.
4. 데스크톱에서 할 일 제목을 계획 타임라인으로 끌어 미리보기를 확인합니다.
5. 놓은 뒤 확인 UI에서 시작 시각·배치 시간·예정 종료를 확인하고 `배치`를 선택합니다.
6. 기존 일정 위에 놓아 겹침 경고와 확인 동작을 점검합니다.
7. 계획 → 할 일에서 기본 액션이 `수정` 하나인지 확인합니다.
8. 수정 화면의 기본 정보·시간 배치·실행 기록 구역을 확인합니다.
9. 모바일 폭에서는 `오늘 할 일 n / m` 목록과 명시적 시간 배치 흐름을 확인합니다.

## 프로토타입 범위

모든 상태 변화는 브라우저의 검토용 로컬 상태에만 반영됩니다. 실제 서버 DB, 인증, 계정 동기화는 구현하지 않았습니다.
