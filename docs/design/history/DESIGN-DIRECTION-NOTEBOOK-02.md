# 디자인 검토 02 — 두 서체로 정리

요약: 손글씨를 제거하고 제호는 Cormorant Garamond 정자체, 제목·본문·메뉴·숫자는 Noto Serif KR로 통일합니다. 사용법 설명은 사용자 예외에 따라 기본 시스템 고딕체를 사용합니다.

## 현재 단계와 적용 범위

기존 기능·정보 관계·데이터 계약을 유지하는 디자인 검토 단계입니다. 검토 02（로컬 자료: `../outputs/Haru-design-study-02.html`）에만 반영했습니다. 본 기능 시안 02.39와 실제 React 앱/API/DB는 변경하지 않았습니다. 검토 01의 손글씨 및 네 서체 제안은 이번 사용자 결정으로 대체됩니다. 색상 최종 선택과 전체 화면 적용은 아직 확정하지 않았습니다.

## 서체 역할

| 대상 | 적용 |
|---|---|
| HaruLeaf 제호 | Cormorant Garamond 500. Haru·Leaf 모두 기울임 없음 |
| 페이지·섹션·할 일 제목 | Noto Serif KR. 크기·무게·여백으로 위계 구분 |
| 본문·메뉴·버튼·입력·단상·회고·실행 이유 | Noto Serif KR. 손글씨 없음 |
| 날짜·시간·집계 숫자 | Noto Serif KR. 주간 요일 옆 날짜 숫자의 서체 지정과 통일, tabular-nums 사용 |
| 사용법·입력 안내·보조 설명 | 기본 시스템 고딕체. 별도 웹폰트 추가 없음 |

주간 날짜 숫자는 요일 `<span>` 다음의 텍스트이며 `.week-day h2` → `--serif` → 검토안의 Noto Serif KR을 상속했습니다. 검토 02는 시간·집계·시계 입력에도 같은 가족을 명시했습니다. 실제 사용자 기기에서 웹폰트가 로딩되어 이 서체로 표시됐는지는 현재 확인되지 않음.

설명글 예외는 타임라인 사용법, 돌아보기 집계 안내, 입력 도움말, 공개 안내, 검토 도구/설명 등에 적용합니다. 할 일 제목·실행 사실·기록 원문·메뉴는 설명글로 분류하지 않습니다. 사용자 요청의 ‘두 서체’는 디자인용 웹폰트 두 가족이며 설명글은 별도 요청에 따른 시스템 서체 예외입니다.

Pretendard·Nanum Pen Script 및 복사본의 나눔명조/조선일보명조 요청은 검토 02에서 제거했습니다. 과거 비교 JSON 안의 역사 자료는 현재 UI의 서체 적용으로 판정하지 않습니다. 신규 폰트 바이너리를 추가하지 않았습니다. 두 웹폰트의 공식 OFL 사용 근거는 [검토 01](DESIGN-DIRECTION-NOTEBOOK-01.md)의 라이선스 기록을 따릅니다.

## 유지한 기능과 검증 한계

여백·가는 선·색상 비교는 유지했습니다. 필수 지표 7개, 근거 펼침, 다음 계획 개선점, 공개 안내, 독립 검토 저장소는 유지했습니다. 기능 삭제나 새 데이터 필드 추가는 없습니다. 이번 서체 변경과 과제 필수 기능의 충돌은 없습니다.

스크립트 구문 및 기존 모의 DOM의 지표·근거·개선점 동작을 점검합니다. 실제 브라우저 시각 검토·웹폰트 로딩·모바일 가독성은 미확인입니다. 완료 체크 잔여 깜박임을 해결한 변경이 아닙니다.
