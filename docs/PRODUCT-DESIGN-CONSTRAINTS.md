사용자 최신 요청으로 docs/T06-ASSIGNMENT-RULE.md를 작업 RULE로 지정했습니다. 원문은 별도 보존하고 본인의 실제 활동만 입력해야 하는 제약을 작업용 지시문에서 제외해 예시/더미를 허용합니다. 최소 계획/할 일/종료 기록 개수 및 정상 집계, 서버 DB 저장/복원 등의 나머지 필수 조건은 유지합니다. 과거 ‘추정 자료를 실제 사용 증거로 간주하지 않음’ 기록과 데이터 유형은 구분하되 더미 사용 자체를 작업 차단 사유로 적용하지 않습니다. 현재 요청은 문서/규칙 변경이며 새로운 자료 생성·업로드를 의미하지 않습니다.

## 02.33 — 상세의 초기 밀도 및 무채색 정리

- 일간 할 일 상세의 예정 시간/실행 기록/단상은 처음 선택할 때 모두 접힙니다. 사용자가 펼친 상태는 완료 체크로 초기화하지 않습니다. 저장한 결과를 의도적으로 펼치는 동작은 별개입니다.
- 단상은 접는 제목 아래에 기존 내용 또는 작성창을 표시합니다. 선택 날짜의 실제 실행에만 적용하며 계획에 적용하지 않습니다.
- 시간 사용 화면의 표시 분류는 작업/휴식/중단입니다. 휴식 이외의 pause/interrupt는 중단에 합산합니다. 유형 미지정 별도 박스/대각선 무늬는 표시하지 않습니다. 내부 구간 및 과거 기록은 보존합니다.
- 주간 범위는 설명 아래·합계 위에 큰 MM.DD–MM.DD로 표시합니다. 7일 그래프와 한 날짜 상세는 유지합니다.
- 바탕/선/글씨는 무채색으로 정리하며 노란색 등 포인트색과 서체(로고 나눔명조·그 밖 조선일보명조)는 유지합니다.
- 일간 완료 체크는 기존 화면 노드를 유지하며 체크 상태와 완료 수만 갱신합니다. 중복 요청/저장 실패/수정 충돌 처리는 유지합니다.
- 목록 접기/펼치기 버튼은 네모 테두리 없는 목록·방향 화살표 아이콘입니다. 접근성 이름/툴팁/키보드 포커스 표시는 제공합니다.

이번 변경은 HTML 시안에 적용했습니다. 실제 React 앱 및 DB 적용은 아직이며 C26/C31/C33 요구사항 보정 대기 상태를 변경하지 않습니다.

## 02.34 — 사용자 재보고 및 제안 기준 강화

접힌 일간 할 일 목록의 외곽 폭을 46→36px로 줄이고 아이콘은 박스 없이 유지합니다. 색감/서체는 변경하지 않았습니다. 사용자 피드백상 체크박스 깜박임이 02.33에도 남으므로 해결 완료가 아닙니다. 원인은 현재 확인되지 않았으며 이번에는 완료 코드를 더 바꾸지 않고 실제 앱의 브라우저 재현/검증 항목으로 넘깁니다.

현재 조선일보명조를 작은 조작 요소에도 쓰고 선/정보 밀도가 높아 고전적인 신문 인상이 날 수 있다는 디자인 의견이 있습니다. 사용자가 새로운 디자인/서체 방향을 승인한 것은 아니며 임의로 서체를 바꾸지 않습니다.

과제 재점검 결과는 outputs/T06-requirements-audit-02.34.md를 따릅니다. C26/C31/C33 직접 충돌 외에 기간 없는 루틴 계획의 C04 구조 보정도 필요합니다. 일반 계획 결과의 대상 범위 명시/정확한 집계/근거, 무인증 공개 제품 URL, 서버 실제 저장 등을 유지합니다. 과제에 벗어나는 제안을 먼저 하지 않으며 사용자 제안에 충돌이 있으면 해당 번호/영향/준수 대안을 구현 전에 반드시 알립니다.

## 02.35 — 승인된 필수 기능 보정

선택 이유/막힘 근거/계획별 개선점 전달/루틴 계획 기간 1~4번 동의 완료. 과거 제거 합의 및 ‘기간 없는 루틴 묶음’은 최신 구현 기준으로 사용하지 않습니다. 단상/회고 독립성, 기본 상세 접힘, 루틴 누적 완료율 제외, 로고 나눔명조·나머지 조선일보명조체, 무채색 및 포인트색은 유지합니다. 다음 계획의 개선점은 계획 결과에서만 전달하며 일반 회고 붙이기 기능은 부활시키지 않습니다. 화면 검토본은 02.35 및 Haru-required-flow-study-01.html입니다. 실제 앱 이식/브라우저 시각 검토는 미완료입니다.

## 02.36 — 화면 승인 및 단상 중복 표시 정리

사용자가 나머지 보정에 동의했습니다. 막힌 이유 입력에는 자동 저장되지 않는다는 안내를 넣고 기존 실행 저장 버튼을 화면 하단에 고정해 발견하기 쉽게 합니다. 독립 이유 저장 버튼을 추가하지 않습니다. 실행별 구형 단상 입력/근거의 단상 표시와 일정 할 일 수정창의 두 번째 단상 영역을 정리합니다. 단상은 선택한 날짜의 일간 상세에서만 편집하며 구형 동일 내용의 중복 출처는 자료를 지우지 않고 표시를 합칩니다. 실제 사용자 브라우저의 동일 현상 재현/확인은 미완료입니다.

## 02.38 — 완료 상태 및 시간 선택

완료한 할 일의 기록 시작/계획 배치/배치 수정은 비활성으로 표시하고 완료 취소하면 다시 사용 가능함을 안내합니다. 수기 실행 기록/정정과 단상은 계속 가능. 완료 체크는 해당 진행 중 기록도 저장/종료하며 별도 확인 팝업을 추가하지 않습니다. 과제 C11/C12/C21/C22/C23~C27 및 근거/집계 기준 유지, 기능 제거 충돌 없음. 휴식/중단 시간은 전체 실행 범위 내 분 단위 선택, 범위 밖 기존 값은 수정 안내. 아이콘 28px SVG 및 기록 시작 80% 크기 적용. 실제 브라우저 시각 검토는 미완료입니다.

## 02.39 — 시간 입력 UX 수정

02.38 분 단위 드롭다운은 사용자 거부로 폐기합니다. 실행 범위 제약을 긴 목록으로 강제하지 않습니다. 휴식/중단은 HH:mm 직접 입력+공통 시계 선택기, 시작 시각에서 5/10/15분 뒤 종료를 제공하며 실행 범위 밖은 선택/빠른 종료 비활성 및 직접 입력 오류 안내. 과제 시간/구간/근거 기준은 유지합니다. 분 단위 저장 정밀도와 분 단위 목록 UI는 별개입니다. 시계의 기본 분 간격은 선택 편의용이며 직접 입력/기존 값은 반올림하지 않습니다.

## 승인한 서체 역할 적용 — 디자인 검토 04
