# 실제 화면 코치마크 검토 — 2026-09-22

요약: 사용자 승인으로 독립 시안을 작성했다. 제품 인증·DB·실제 기록에는 적용하지 않았다.

## 안내 흐름

새 사용자: 새 계획 → 계획 입력/저장 → 할 일 추가 → 할 일 입력/저장 → 일정 → 할 일 선택 → 배치와 기록 시작 설명. 마지막 단계에서 타이머를 시작하지 않고 끝낼 수 있다.
기존 자료 사용자: 기존 할 일 선택 → 배치/기록 설명. 실제 제품에서는 자발적으로 안내를 켤 때만 시작한다. 시안 경로 선택은 검토 도구다.

현재 앱의 승인 CSS와 계획 화면 역할/주요 입력을 재사용한 독립 HTML이다. 실제 React 앱 전체를 복제한 것은 아니다. 이번 경로에 필요한 계획/일간 부분을 구성했고 돌아보기/보관함 등은 검토 범위 안내로 표시한다. 제품 기능 삭제가 아니다.

안내 종료/Escape, 다른 메뉴 이동 시 일시 중지, 다시 보기, 신규/기존 경로 전환을 제공한다. 시안 자료는 메모리에만 존재하고 새로고침 시 초기화된다. 입력한 제목은 HTML 이스케이프한다. 타이머·배치 동작은 생성하지 않는다.

## 후속 제품 적용 조건

계정별 완료/중단 상태 저장, 최초 종료 기록 뒤 돌아보기, 단상 최초 열기, 하루 마무리의 회고 안내는 후속 구현 범위다. 서버 저장 성공 후 다음 단계, 저장 실패 시 현재 단계 유지가 필요하다. 중단 후 재개에는 계정 자료 유무/삭제 여부를 다시 검사한다.

## 검증과 한계

JavaScript 구문 검사 통과. 브라우저 직접 렌더링·폰트 로딩·모바일 키보드 검증은 아직 하지 못했다. 이전 로컬 파일 열기 보안 차단을 우회하지 않는다. 모바일 하단 안내와 입력 집중 시 일반 흐름으로 이동하는 CSS는 구현했으나 실기 확인이 필요하다. 생산 앱에 배포하지 않았다.

## 2026-09-22 수정 — 입력 강제 제거 / 배경 강조

최신 시안은 [코치마크 02](studies/Haru-onboarding-study-02.html)다. 앞의 실제 작성/저장 필수 진행안을 대체한다. 모든 안내 단계에 다음 버튼을 제공하고, 작성 없이 예시 계획/할 일을 메모리에서 보여준다. 실제 제품에서도 안내용 예시는 사용자 자료로 저장하지 않아야 한다. 직접 입력은 선택이며 실제 작성은 안내 이후 가능해야 한다.

강조 대상 외 영역에 검정 불투명도 70%를 적용하고 대상 경계는 노란색으로 표시한다. 안내 종료/완료 시 가림을 제거한다. 스크롤·창 크기·레이아웃 변화에 강조 위치를 맞춘다. 시안의 장막은 포인터 이벤트를 가로채지 않는다.

JavaScript 구문 및 다음 버튼 존재 확인 완료. 직접 렌더링/모바일 실기 확인은 아직 미완료이며 서비스에 배포하지 않았다.

## 2026-09-22 필기 안내 방향 — 시안 03

사용자는 손글씨 안내안을 선택했다. 신문에 잉크펜 동그라미, 형광펜 표시, 새파란 펜 설명을 덧쓴 분위기다. 배경 가림/노란 사각 테두리는 제거한다. 손글씨 제거 결정의 예외는 사용 안내에 한정하며 기존 제목·본문·사용자 기록의 서체는 그대로 유지한다.

[필기 안내 시안 03](studies/Haru-onboarding-study-03.html): 가는 잉크색 타원, 반투명 형광펜 한 줄, 파란색 #1048e5의 한글 손글씨. 입력 폼 전체가 아니라 해당 제목 입력창, 할 일 제목, 기록 시작 버튼을 대상으로 표시한다. 데스크톱은 안내용 오른쪽 여백, 모바일은 관련 구역 뒤에 주석을 배치한다. 이전/다음/건너뛰기는 기존 산세리프. 실제 입력은 필수가 아니다.

안내 서체는 Nanum Pen Script 400을 시안에 한정 적용했다. Google Fonts 저장소의 OFL 1.1에서 임베딩 허용을 확인했다: https://raw.githubusercontent.com/google/fonts/main/ofl/nanumpenscript/OFL.txt . 글꼴 로딩과 렌더링/모바일 실제 시각 검증은 미완료. JavaScript 구문 확인만 통과. 제품 배포/자료 저장 없음.

## 필기 시안 04 — 사용자 참조 질감 반영

매끈한 SVG 타원을 파란 거친 펜자국 PNG로 교체. 계획 제목/할 일 제목 라벨에 span을 두고 텍스트 범위만 강조한다. 입력 필드 전체 강조 금지. 사용자가 지정한 GeuriunXKukhanbakTture 400 CDN을 안내에 적용했다. ~해요 문체를 안내에서 제거했다. 해당 서체의 별도 라이선스 검증/실제 브라우저 폰트 로딩은 아직 미확인.

내장 image_gen 사용. 생성 프롬프트 요지: 투명 배경, 선명한 파란색 #1048e5, 손으로 급히 두 번 그린 타원, 거친 잉크 입자와 압력 차이, 텍스트/그림자/종이 없음. 밑줄 프롬프트: 투명 배경, 버건디 #75444b, 두 획의 거친 손그림 가로 밑줄, 글자/그림자 없음. 원본 PNG를 assets에 그대로 저장. 생성 이미지는 직접 확인했으나 전체 시안 브라우저 렌더링 검증은 미완료. JavaScript 구문 확인 통과.

화살표 삭제. 제목은 첫 계획 만들기로 수정. 안내 경로 이름은 없애고 손글씨 카운트 1/7만 설명 아래 우측에 배치. 동그라미 세 PNG를 내장 image_gen으로 생성해 단계별로 배정했다. 프롬프트: 투명 배경의 선명한 코발트 잉크, 축소에도 유지되는 두꺼운 거친 획, A 오른쪽 위로 기운 타원과 아래 겹침, B 왼쪽이 불룩하고 우상단 열린 꼬리, C 오른쪽으로 처지고 왼쪽 교차 획. 생성 이미지 원본은 assets/blue-ink-circle-a,b,c.png. 버튼은 테두리에 정확히 맞추지 않고 바깥 여백/위치/기울기를 단계별로 조정한다.

## 시안 06 — 원본 표시 / 스크롤 위치 보정

새 계획·할 일 추가 등은 사용자 원본 original-ink-circle.png 그대로 사용. 이미지 생성 색변환에서 원치 않는 발광이 생겨 불채택했다. 원본을 SVG 색행렬로 R/B 채널 교환해 파란색으로 표시하고 multiply로 흰 배경 처리. 원본 픽셀 파일은 무변경. 추가 회전 제거.

강조 표시 fixed + 매 scroll 위치 재계산 구조를 absolute + 문서 좌표로 변경, scroll 리스너 삭제. 단계 변경/resize/폰트 로딩 시 배치 갱신 유지. 코드상 덜그럭거림 원인을 제거했으나 실제 브라우저 스크롤 검증 미완료. JS 구문 통과. [시안06](studies/Haru-onboarding-study-06.html).

## 시안 07 — 소방관의 기도 / 대광유리 비교

사용자 지정 두 CDN WOFF를 받아 동일 문구·38px·동일 줄 간격·색으로 Pillow에 렌더링했다. 비교 이미지는 studies/Haru-guide-font-comparison.png. 실제 브라우저의 렌더링과는 구분한다. 두 서체 모두 가는 펜 획. 디자인 판단: 소방관의 기도는 상대적으로 글자 폭과 간격이 조밀하고 문장 덩어리가 안정적이며 대광유리는 더 넓게 벌어지고 자유로운 리듬이다. 제한된 안내 폭에는 소방관의 기도 선택.
