# T06 02.13 테스트 보고서

한 줄 요약: 이번 변경에 대한 자동 점검 14개가 통과했습니다. 실제 브라우저 조작 테스트는 아닙니다.

## 점검 결과

1. HTML 내 실제 스크립트 구문 및 초기화.
2. 다음 달 계산: 평년·윤년 1월 말, 연도 변경, 일반 날짜.
3. 일반 계획의 날짜 입력 유지.
4. 루틴 계획의 날짜 입력 제거 및 기간·성공 기준·예상 시간 없이 저장.
5. 새 루틴 기본 오늘/한 달 뒤 날짜 입력 표시.
6. 기본 기간 저장 및 종료일 당일 포함.
7. 시작일·종료일 달력 열기/닫기. 실제 선택자와 존재하지 않는 ID 조건을 구분한 대체 문서 사용.
8. 상위 계획 범위와 독립적인 날짜 저장. 기본 종료일의 시작일 추종 및 직접 지정한 종료일 보존.
9. 역전·잘못된 날짜 저장 차단.
10. 반복 규칙 수정에서 독립 종료일 표시 및 완료한 날짜 보호.
11. 루틴 계획 제목 수정 시 날짜별 할 일·실행 기록 불변.
12. 하루 수정 화면에서 불필요한 상위 기간·종료일 입력 제거.
13. 기존 작업 49분·멈춤 25분 계산 유지.
14. 이전 버전 자료 복사 및 이전 저장값 불변.

## 방법과 한계

Node에서 실제 HTML 스크립트를 실행하고 문서·저장소를 대체 객체로 제공했습니다. 실제 클릭, 화면 레이아웃, 모바일, 키보드, 드래그 회귀 검증은 하지 않았습니다. 기존 02.12의 56개 검사가 새 버전에서 모두 통과했다는 의미가 아닙니다.

재현: 검토 묶음 루트에서 `node work/test-v213.cjs`. 같은 묶음의 `work/test-v212.cjs`는 공통 대체 문서 설정을 읽는 데 사용하며 이전 검사를 실행하지 않습니다.

## 직접 확인 순서

새 계획 → 루틴 계획 선택 → 날짜 없이 저장 → 반복할 할 일 입력 → 기본 기간 확인 → 시작일/종료일 변경 → 생성 → 수정의 이후 반복 확인 → 날짜별 이력에서 일간 이동.

모바일에서는 날짜 버튼과 명시적 시간 관리로 같은 흐름을 확인합니다. 이전 시안과 원본은 보존했습니다.
