# 02.27 로고 변경 범위 정정

02.26에서 요청 범위를 넘어 본문과 일반 제목을 바꾼 것을 철회합니다.

- HaruLeaf 로고만 나눔명조 800. 크기 48px / 모바일 38px.
- 나머지 서체 지정은 02.25의 조선일보명조체로 복원. 프리텐다드 제거.
- 따뜻한형 제거 유지. 저장 자료와 서비스 동작 유지.
- 눈누 조선일보명조체 페이지에서 동일 WOFF 제공 및 웹/임베딩/BI·CI 허용 확인.
- 코드 검사: 원래 UI·serif·회고 제목 스택 복원, 나눔명조 지정은 로고 하나, 따뜻한형 없음, inline JS 구문 검사 통과.
- 브라우저 최종 렌더링은 아직 미확인.
