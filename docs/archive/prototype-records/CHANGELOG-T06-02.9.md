# T06 02.9 변경 기록

한 줄 요약: 02.8을 보존하고 배치 확인을 중앙 팝업으로 바꾸며, 돌아보기 판단을 위한 상호작용 시안을 추가했습니다.

## 현재 프로젝트에 실제 구현된 기능

아래는 서버 기능이 아닌 HTML 프로토타입의 상태 변화입니다.

- 드래그 후 중앙 배치 확인 팝업: 시작 시각, 배치 시간, 예정 종료 표시. 취소·Escape로 저장 없이 종료. 겹치는 일정은 확인 체크 후 배치. 저장 실패 시 입력 유지.
- 15분 위치 맞춤과 할 일 예상 시간 기준 길이 유지. 드래그 중 타임라인 가장자리 스크롤 처리 유지. 명시적 시간 배치 경로 유지.
- 실제 기록 툴팁의 멈춤 합계 표시를 간소화했습니다. 상세에서는 `멈춤 · 유형 미지정`으로 설명하고, 기록 수정에서 유형 미지정/휴식/중단 선택을 제공합니다. 모두 작업 시간에서 제외합니다.
- 돌아보기의 `계획 결과 / 날짜별 시간 사용 / 회고` 구역을 분리했습니다.
- 계획 결과: 완료·지연 등 수치의 근거를 열고 할 일 또는 실행 기록으로 이동한 뒤 돌아오기.
- 날짜별 시간 사용: 주간 이동, 날짜별 펼치기, 자정 기준 기록 분할, 작업·휴식·중단·유형 미지정 구분. 진행 중 기록 제외.
- 회고: 날짜별 작성·수정, 관련 계획 선택, 수정 전 값 보존, 하루 마무리 시 빈 회고 허용. 기록 종료나 하루 마무리로 할 일을 자동 완료하지 않습니다.
- 회고 전체/문장 책갈피, 검색, 기존 계획에 문장 붙이기, 원문 연결. 저장한 발췌 문장은 원문 수정과 독립적으로 보존합니다.
- 공개 서비스처럼 읽히던 안내를 서버·DB 미연결 시안 안내로 변경했습니다.

## 구현되지 않은 기능

- 일반 계획/루틴 계획 선택 및 반복 생성: 기획 결정만 기록했습니다. 02.9 화면에 구현하지 않았습니다.
- 계획 생성 화면에서 책갈피를 고르는 기능: 아직 없습니다. 현재는 계획을 만든 뒤 회고에서 해당 계획에 붙입니다.
- 반복 예외 처리, 휴지통, 실제 서버 저장, 계정·권한, 배포, PDF 내보내기, 타임라인 블록 크기 조절.

## 서비스가 지원하지만 현재 사용하지 않는 기능

연결된 외부 서비스가 없습니다. 특정 서버나 DB 서비스의 기능을 조사·도입한 작업이 아닙니다.

## 확인이 필요한 불확실한 부분

- 돌아보기 구성은 승인 대기 중인 검토안입니다.
- 브라우저 접근 제한으로 실제 데스크톱/모바일 조작 및 시각 검증은 수행하지 못했습니다. 테스트 보고서의 미검증 항목을 확인해야 합니다.
