# T07 구현 진행 — 2026-09-22

요약: 인증 기반 코드를 작업 브랜치 codex/t07-auth에 추가했다. 운영 앱은 아직 T06 공개 방식이다.

## 로컬 구현 및 검증

- 새 비밀번호 검증: 8자 이상, 공백 금지, 한글 허용, 조합 강제 없음. 입력 자동 변환 없음. UI 연결 및 서버 Auth 강제 조건 검증은 미완료.
- 계정-다이어리 1:1 연결 테이블과 서버 세션 검사. 이메일 미확인, 세션 삭제, 7일 초과, 다른 사용자의 세션 거절.
- 복구/OTP 중간 세션은 자료 접근 거절. 현재 기반은 password AMR만 허용하므로 가입 확인 직후 연결 흐름은 추가 구현 대상.
- 기존 SQL 0001–0010을 모두 설치한 로컬 PostgreSQL 호환 환경에서 공개 고정 ID를 계정별 ID로 바꾸는 전환 SQL을 실행하고 목록/내보내기 분리, 양방향 변경·삭제·타인 계획에 생성 거절, 거절 후 자료 불변을 검증.
- 새 테스트 6개 통과. Auth 테이블과 JWT 주입은 로컬 검증용 대역이다. 실제 Auth 로그인·HTTP 403/404·발송·로그아웃 증거로 제출하지 않는다.

## 운영 적용 전 남은 작업

staged-t07 디렉터리는 자동 적용 마이그레이션이 아니다. 공개 RPC 차단은 메일, 가입 화면, 서버 제한, 기존 자료 소유자 확인과 함께 전환해야 한다. 실제 NAS에는 적용하지 않았다.

개별 조회 404 증거, 가입/복구 번호 시도 제한, 비밀번호 변경 후 전 세션 종료, 서버 비밀번호 조건, 사용자 생성/자료 이전, 계정 삭제/백업 정책, 내보내기 화면, 실제 5일 사용은 미완료다. 로컬 테스트가 이를 대신하지 않는다.

## 메일 연결

Resend auth.haruleaf.com 도메인 검증 완료를 관리 화면에서 확인. 발송 지역 Tokyo. Cloudflare rsend.auth CNAME을 Resend 요구값 rsend-apne1.forge.rmta.net으로 보정했다. 웹 서비스 A 레코드와 기존 라우팅은 변경하지 않았다.

발송 전용·auth.haruleaf.com 제한 API 키 생성 양식 준비. 신규 발송 권한 생성 및 NAS 저장 확인 대기. 키 미생성, SMTP 미연결, 실제 메일 수신 미검증.

## 메일 설정 후속

전체 로컬 테스트 61/61 통과. 사용자 승인으로 도메인 제한 발송 키를 생성해 NAS Supabase SMTP 설정에 반영, SMTP 연결 인증 성공 및 기존 Auth 이미지 보존 확인. 실제 메일 미발송.

키 표시 대화상자를 닫는 직후 브라우저 도구가 닫히는 중인 내용을 출력하여 비밀값이 노출됨. 원문은 이 문서에 기록하지 않는다. 해당 키로 발송을 진행하지 않고 폐기·재발급 승인을 요청했다. 교체 및 검증 완료 전 SMTP 준비 완료로 판정하지 않는다.

## 메일 연결 검증 완료

노출 키 폐기 확인 후 동일한 발송 전용·도메인 제한 키를 재발급하여 NAS 설정 교체 완료. 교체 키는 출력하지 않았다. SMTP 연결 확인 메일 한 통을 발송하고 사용자에게 실제 도착 확인을 받았다. 가입 OTP·복구 OTP 수신 검증은 아직 별개로 남아 있다.

가입 확인/비밀번호 재설정용 HTML 메일 템플릿 소스 추가. 외부 이미지·추적·웹폰트 없이 제호/지면/큰 번호 구성. 이 템플릿은 아직 서버에 연결하지 않았으며 10분 문구는 실제 Auth 설정과 함께 적용해야 한다. 메일 클라이언트별 시각 검증 미완료.
