## 배포 중 발견한 설정 오류와 복구

첫 정적 빌드에서 `NEXT_PUBLIC_HARU_PRIVATE=1`을 빠뜨려 공개 T06 모드의 화면이 생성됐다. 이를 새 릴리스로 잠시 올린 뒤, 브라우저 검증에서 공개 안내 문구와 개인 모드가 꺼진 화면을 발견해 즉시 직전 T07 릴리스로 되돌렸다. 이후 보호 모드를 명시해 다시 빌드하고, 정적 HTML에 공개 안내 문구가 없으며 개인 로그인 확인 화면이 있음을 배포 전 검사했다. 잘못 빌드한 릴리스 디렉터리는 활성 상태가 아니며 `DO_NOT_DEPLOY` 표시를 남겼다. 잘못 빌드한 짧은 구간의 외부 열람 여부는 현재 확인되지 않는다. DB 접근 정책은 변경하지 않았으나, 그 구간의 모든 요청을 조사했다는 뜻은 아니다.

재발 방지를 위해 `web/scripts/build-static.mjs`는 보호 모드 환경 변수가 없으면 빌드를 거절하고, 완료 뒤에도 개인 화면 문구와 공개 안내 부재를 확인하도록 수정했다. `web/scripts/smoke-static.mjs`도 현재 T07 기준으로 갱신했다. 보호 변수 없이 실행하면 종료 코드 2, 변수를 주면 빌드·정적 HTTP 검사가 통과하는 것을 확인했다. 이 스크립트 보강은 배포 화면 소스 `d0aed89` 뒤의 후속 커밋이다.
