# 일간 할 일의 계획 시작일 필터

요약: 선택한 날짜보다 나중에 시작하는 계획의 할 일이 일간 목록에 나타나던 오류를 수정했다. 9월 15일에는 9월 23~24일 부산 여행 계획의 할 일이 보이지 않아야 한다.

## 원인과 변경

- 기존 일간 목록은 취소 여부와 루틴 발생 날짜만 검사했다. 일반 계획의 시작일은 검사하지 않아, 아직 시작하지 않은 계획의 할 일도 과거 날짜에 표시됐다.
- 일반·루틴 모두 선택 날짜가 계획 시작일보다 빠르면 일간 목록에서 제외한다. 루틴은 기존처럼 해당 발생 날짜에만 표시한다.
- 계획 종료일을 지난 미완료 일반 할 일은 계속 목록에 남긴다. 기한을 넘긴 일을 확인할 수 있어야 한다는 기존 사용자 결정을 유지한다.
- 데이터 저장, 완료 상태, 주간·월간 표시, 일정 배치 방식은 변경하지 않았다.

## 확인

- 수정 전 운영 사이트에서 9월 15일을 선택하고 일간 목록을 펼치자 `부산 여행`, `부산 여행 종이 다이어리 꾸미기`, `Haru 디자인 다듬기`, 10월 시작 `T07 · 인증 후 실제 5일 사용 관찰`까지 표시됐다. 이는 해당 날짜에 계획이 없다는 뜻과 다르게 미래 계획을 섞은 재현 결과다.
- 날짜 경계 회귀 검사: 9월 15일에는 23일 시작 계획을 제외하고, 23일에는 포함하며, 25일에도 미완료 일반 할 일은 유지한다.
- 관련 단위 검사 5개, TypeScript 검사, 비공개 정적 빌드 및 정적 산출물 점검 통과.
- 로컬 시안에서 9월 15일을 선택하면 해당 미래 계획이 목록에 나타나지 않는 것을 확인했다.
- 배포용 비공개 정적 빌드를 다시 만들고 HTTP 산출물 점검을 통과했다. 전송 준비 파일은 `D:/workspace/T06-palndosee/outputs/t07-daily-date-filter-5a3683c.tar.gz`이며 SHA-256은 `9CA4B4113DAD9DB94CC4EBCB01D1130FD297C716B4516D96D57EBCE90C19BA13`이다.
- 운영 사이트 반영 및 운영 계정으로 날짜 재확인은 아직 완료되지 않았다. 로컬 검사 결과를 운영 검증으로 표현하지 않는다.
