- 짧고 하나의 단어처럼 읽히는 이름. 신문·지면 콘셉트를 살리는 방향.
- HaruFolio의 분위기는 긍정적이나 길이가 부담됨.
- 짧게 Haru, 전체 이름이 필요한 곳에서는 HaruFolio를 쓰는 방식 또는 Folio를 다른 단어로 교체하는 방식을 검토 중.
- Harlio(할리오)는 비선호. 하루면에만 한정하지 않고 다양하게 검토.

## 어휘 조사와 후보

아래 단어들은 모두 Folio의 정확한 유의어가 아닙니다. 종이·출판·일상 기록이라는 관련 의미를 바탕으로 고른 후보입니다. 이름에 부여한 서비스 이미지는 브랜드 제안입니다.

| 전체 이름 후보 | 관련 의미 | 평가 |
|---|---|---|
| HaruFolio | 접은 종이, 책의 잎, 페이지 번호 등 | 기존 후보. 지면 느낌이 있으나 길이 부담 |
| HaruLeaf | 책 속 종이 한 장 | 짧고 부드러움. 나뭇잎 의미도 먼저 연상될 수 있음 |
| HaruJournal | 일상 기록, 신문 | 계획·실행·회고와 신문 콘셉트를 함께 설명하기 좋음 |
| HaruPress | 인쇄·언론·출판 관련 의미 | 신문 분위기는 선명하지만 출판사 같은 인상도 있음 |
| HaruEdition | 책·신문의 판, 발행된 버전 | 하루마다 만들어지는 판이라는 이미지. 짧지는 않음 |
| HaruGazette | 신문, 관보 | 고전 신문 분위기. 한국어 발음 친숙도 검토 필요 |
| HaruChronicle | 시간 순서의 사건 기록 | 기록 의미는 강하지만 이름이 길고 무거움 |

짧은 표시 Haru + 전체 이름은 단일 브랜드의 표기 체계로 검토합니다. 띄어쓰기/붙여쓰기/대문자 로고는 이름 선택 후 확정합니다. 좁은 화면에서도 서비스명을 알아볼 수 있게 하고, 신문 장식 때문에 주요 행동의 가독성을 낮추지 않습니다.
