# 현재 작업 기준

승인 시안은 02.24이며 현재는 실제 구현 단계입니다. 요구사항·화면 흐름·데이터 계약·기술 구성은 합의됐습니다.

- 기술: React / Next.js / TypeScript, Supabase PostgreSQL, Vercel.
- GitHub: https://github.com/suminkim8203/haru-journal (공개).
- 구현: 일반 계획 생성, 할 일 생성·완료 처리, 저장 API, SQL 트랜잭션, 중복 요청 방지 및 수정 충돌 감지.
- 검증: 타입 검사, 프로덕션 빌드, 테스트 9개, HTTP 실행 검사 통과.
- SQL은 로컬 PostgreSQL 호환 PGlite에서 검증했습니다. Supabase 원격 적용·실제 기기 간 저장·브라우저 시각 검토는 아직입니다.
- Supabase 새 프로젝트 생성은 사용자 승인됨. 계정 접근 및 생성은 아직 완료되지 않았습니다.
- 다음: Supabase 연결 → 실제 저장 확인 → 계획/할 일 수정·휴지통 → 일정·실행 기록 → 단상·회고·돌아보기.

현재 React 앱은 첫 구현 범위만 제공합니다. 승인 시안 전체를 이식한 상태가 아닙니다. 자동 삭제·인증·사용자별 소유권은 이번 범위 밖입니다. 회고는 날짜에 독립하며, 보관함은 회고 모음/휴지통 두 탭입니다. 단상은 실제 실행한 할 일과 날짜별 하나입니다.

오래된 이전 문서는 역사 기록입니다. 최신 제품 계약은 IMPLEMENTATION-DECISIONS.md 및 DATA-CONTRACT-v1.md를 참고합니다. 화면 확인을 매 단계 요청하지 않으며, 실제 연결 후 핵심 흐름을 묶어서 사용자 검토를 받습니다.
