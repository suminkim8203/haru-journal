## 과제 필수 기준과 승인 결정

- 막힌 이유 저장(C26), 막힘 수(C31), 다음 계획 개선점 전달(C33), 루틴 계획 기간(C04/C08)은 최신 보정안에서 유지됩니다. 예전 제거 결정이 현행 승인으로 적용되는 상태가 아닙니다.
- 단상과 회고의 독립성, 회고만의 책갈피, 보관함 두 탭, 루틴 누적 점수/챌린지 제외, 서체·폭·날짜 줄·펜 선 변경에서 새로운 과제 충돌은 확인하지 않았습니다.
- 과제 C28~C33/C83 집계·같은 근거 이동, 실행 시간/이유, 원본/수정 이력, 태그/검색/필터/정렬, 실제 DB 저장·복원, 전체 내보내기, 공개 안내 및 제출 증거는 실제 앱에 계속 구현·검증해야 합니다. 디자인 승인으로 충족했다고 판정하지 않습니다.
- 최소 계획 1개·소속 할 일 5개·종료 실행 3개·정상 집계를 서버 DB에서 확인해야 합니다. 더미 허용 예외는 이 조건을 면제하지 않습니다.
- T06 자동 영구 삭제 없음, 30일 정책은 T07 검토 사항입니다. 오래된 문서의 30일 표현을 지금 운영 정책으로 가져오지 않습니다.

## 플랫폼은 지원하지만 현재 앱에서 사용하지 않는 기능

Supabase Auth/Realtime/Storage/Edge Functions가 설치되어 있다는 기록과 해당 제품 기능 구현은 별개입니다. 현재 앱의 회원가입·초대·이메일 확인·계정 활성화·최초 비밀번호 설정·비밀번호 변경·재설정 흐름, OAuth/이메일 발송은 구현/검증되어 있지 않습니다. 관리자 접근용 인증과도 구분합니다. 이 검토를 이유로 T06 범위에 새 인증 기능을 추가하지 않습니다.
