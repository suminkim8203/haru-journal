## 공식 사용 범위 확인

### Georgia 및 Windows 기본 대체 서체

Microsoft 공식 FAQ는 Windows 서체를 CSS font stack에 지정해 방문자의 설치된 폰트로 표시하는 것을 허용합니다. Windows 폰트 파일을 웹 서버로 복사하거나 WOFF/WOFF2로 변환하는 권한은 기본 이용 조건에 포함되지 않습니다. 배포·번들·웹폰트는 별도 권한이 필요합니다.

Windows 제공 서체로 로고/광고 같은 그래픽 결과물을 만드는 것은 허용하며, 사용 제작 도구가 가정/학생/비상업 전용 라이선스인지도 구분해야 합니다. 이미지 결과물과 폰트 파일 배포는 다릅니다. 타 OS/별도 구매본은 해당 공급 라이선스를 확인합니다.

출처: [Microsoft font FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq), [Georgia family](https://learn.microsoft.com/en-us/typography/font-list/georgia).

### 조선일보명조체

조선미디어 공식 소개는 누구나 이용하도록 공개·보급한다고 안내합니다. 공식 100주년 서체 안내는 개인/기업 무료 제공, 자유 배포, 복사·배포 대가 요구 금지, 수정 판매 금지, 배포된 형태 그대로 사용 조건을 명시합니다. 무료 공개를 OFL 라이선스로 해석하지 않습니다.

현재 시안의 URL은 공식 원본 다운로드가 아닌 제3자 WOFF입니다. 공식 안내만으로 이 파일의 버전·원본 대응·포맷 변환 허용 근거까지 확인되지는 않습니다. 상업 서비스에 그대로 사용할 웹폰트 파일로 완전히 검증됐다고 단정하지 않습니다. 공식 배포본 이용 조건과 변환/웹 배포 권한을 확인하거나 명확한 OFL 서체를 선택합니다.

출처: [공식 소개](https://about.chosun.com/mobile/pages/intro_ci.php), [공식 100주년 서체 안내](https://event.chosun.com/100/100font.html).

### 고운돋움

저작자 프로젝트와 Google Fonts 배포본에서 SIL Open Font License 1.1을 확인했습니다. 상업 이용·웹폰트·소프트웨어 포함 배포 및 수정 가능. 폰트 단독 판매 금지, 폰트 배포 시 저작권·라이선스 포함, 수정본의 예약 이름 조건 준수, 폰트 자체의 OFL 유지가 필요합니다. 생성한 문서/로고 결과물을 OFL로 공개할 의무는 없습니다.

현재 CDN 파일이 공식 배포본과 같은 바이너리인지와 파일 내부 고지는 확인하지 않았습니다. 자체 호스팅 시 검증된 공식 배포본과 라이선스를 함께 관리합니다.

출처: [저작자 프로젝트](https://github.com/yangheeryu/Gowun-Dodum), [배포 라이선스](https://raw.githubusercontent.com/google/fonts/main/ofl/gowundodum/OFL.txt), [OFL 공식 본문](https://openfontlicense.org/open-font-license-official-text/).
