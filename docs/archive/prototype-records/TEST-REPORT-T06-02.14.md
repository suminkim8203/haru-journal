주요 확인 내용:

- 일반 할 일 5개 + 7일 루틴 1개에서 계획 결과는 5개입니다. 루틴 날짜별 7개 자료와 ID는 그대로입니다.
- 완료·지연·막힘·예상·실제·차이가 일반 계획 대상에 맞으며, 같은 할 일에 막힘 기록이 여러 개 있어도 한 번 셉니다.
- 완료한 과거 할 일은 지연으로 중복 집계하지 않습니다. 빈 집계는 0입니다.
- 루틴 실제 시간이 날짜별 시간 사용에 남고, 한 날짜 완료가 다른 날짜로 전파되지 않습니다.
- 특정 계획을 선택한 근거에는 계획 이름이 없으며, 제목이 같은 독립된 할 일을 합치지 않습니다.
- 근거에서 작업·멈춤 시간, 날짜, 메모 및 세부 구간을 확인할 수 있고 계획 결과에 이동 버튼이 없습니다.
- 제목·설명·계획 이름·메모에 넣은 HTML 문자열을 이스케이프합니다.
- 근거 펼침은 페이지나 도메인 자료를 바꾸지 않습니다.
