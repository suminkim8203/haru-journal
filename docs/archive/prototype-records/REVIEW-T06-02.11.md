# T06 02.11 검토 안내

한 줄 요약: 계획에서는 반복 규칙, 일정·일간에서는 그날의 실행을 관리합니다.

## 확인 순서

1. 계획에서 루틴 계획 선택. 독서나 스트레칭이 기간에 상관없이 한 줄씩만 나오는지 확인합니다.
2. 반복 할 일 추가. 처음에는 계획 기간과 동일이라는 요약만 보이고 날짜를 다시 입력할 필요가 없어야 합니다.
3. 이 할 일의 반복 기간 따로 설정 선택. 이때만 날짜 입력을 확인합니다. 선택 해제하면 계획 기간으로 돌아갑니다.
4. 루틴 행의 수정. 반복 조건을 바꾸고 적용 대상 확인을 누릅니다. 특정 날짜 완료가 아니라 이후 반복 규칙 변경으로 안내되어야 합니다.
5. 날짜별 이력. 선택한 루틴의 기본 7일만 나옵니다. 기간을 넓혀도 한 페이지에는 최대 20개만 나옵니다.
6. 이력에서 일간 보기. 해당 날짜의 할 일로 이동해 완료·기록·날짜별 수정·건너뛰기를 처리합니다.

## 유지한 기능

드래그 배치 확인 팝업, 명시적 시간 배치, 수동 실행 기록 정정, 돌아보기, 날짜별 완료·예외 보존, 밝은 기록 종료 버튼과 sticky 하단 영역.

## 미결정 또는 이번 범위 밖

계획 기간을 나중에 변경했을 때 기존 루틴에 일괄 전파하는 확인 정책, 반복 재개·취소/복원, 실제 서버 개발. 현재는 새 루틴 생성 시 계획 기간을 기본으로 사용합니다.
