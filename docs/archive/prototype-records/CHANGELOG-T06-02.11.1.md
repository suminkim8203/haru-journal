# T06 02.11.1 — 달력 열기 오류 수정

한 줄 요약: 달력의 오늘·내일 버튼을 잘못 찾던 연결을 수정했습니다. 삭제 기능은 정책 검토 전으로 구현하지 않았습니다.

## 현재 프로젝트에 실제 구현된 수정

- 이전 코드는 실제 HTML에 없는 `#date-picker-today`, `#date-picker-tomorrow`를 찾고 해당 요소의 disabled 값을 변경했습니다.
- 이 시점에 `Cannot set properties of null (setting 'disabled')` 오류가 나서 달력 열기가 중단되는 것을 실제 스크립트 실행으로 재현했습니다.
- 실제 존재하는 `data-action` 버튼을 달력 내부에서 찾도록 변경하고 요소 존재 여부를 확인합니다.
- 루틴 범위 밖 오늘/내일 선택 제한을 유지하며, 일반 계획 달력에서는 제한 상태를 초기화합니다.
- 날짜별 목록·루틴 기간 UI와 완료/실행 기록 정책은 변경하지 않았습니다.

## 구현되지 않은 기능

할 일 수정 화면의 삭제 기능은 사용자 추가 제안에 따라 검토 중입니다. 일반 할 일/반복 날짜/루틴 전체의 적용 범위와 기존 실행 기록 보존·복원 정책을 확정한 뒤 반영합니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스 추가 없음. 서버·DB가 없는 HTML 시안입니다.

## 확인이 필요한 부분

실제 브라우저의 달력 표시 위치·터치·키보드 조작은 미검증입니다. 자동 검사 환경에서 발생 원인 재현, 수정 후 달력 열기·닫기·날짜 반영은 확인했습니다.
