# 서체 역할 재설계 — 독립 A/B 비교

요약: 큰 제목·긴 읽기 본문에 조선일보명조를 남기고 작은 정보·조작은 Pretendard로 분리하는 A안을 우선 추천합니다. B안은 긴 읽기 본문에만 리디바탕을 추가합니다. 추천/조정값은 디자인 가설이며 직접 브라우저 렌더링 검증은 미완료입니다.

## 단계와 적용 범위

기능/정보 구조를 유지한 디자인 검토 단계입니다. 독립 비교（로컬 자료: `../outputs/Haru-typography-study-01.html`）, A（로컬 자료: `../outputs/Haru-typography-A-01.html`）, B（로컬 자료: `../outputs/Haru-typography-B-01.html`）를 작성했습니다. 본 기능 시안 02.39, 기존 디자인 검토 03, 실제 React 앱/API/DB는 변경하지 않았습니다. 두 후보는 동일 02.39 런타임과 동일 예시를 사용합니다. 집계 7개/근거 이동/공개 안내/편집 기능 유지, 새 데이터 필드 없음. 손글씨/Noto Serif KR 없음.

서체 수: A 조선일보명조 + Pretendard + 영문 제호 Cormorant Garamond = 3가족. B 여기에 리디바탕 = 4가족. 제호의 영문 대비/비례 유지가 Cormorant를 남기는 이유입니다. 전체 두 가족 완료라고 설명하지 않습니다.

독립 저장 키 haru.typography-study.v1.A.* 및 B.* 사용. 본 자료를 읽거나 복사하지 않습니다. 다시 열거나 비교 화면/단계를 바꾸면 독립 예시로 시작합니다. 각 후보의 편집은 해당 검토 자료만 변경합니다. 긴 글은 디자인 검토용 예시이며 실제 활동 증거가 아닙니다. 서버 미연결 안내/제품 적용용 무인증 공개 안내를 유지합니다.

## 두 단계 비교

1. 서체 자체: 같은 문장·16px·400·행간 1.8·자간 0·최대 폭 320px·같은 잉크색의 세 서체 표본. 실제 A/B 긴 본문도 16px·400·1.8·0·최대 폭 660px·같은 색으로 비교.
2. 조정 후보: A 긴 글 18px/1.95/−.01em, B 18px/1.85/0. 모바일 둘 다 17px, A 1.9/B 1.85. 두 안의 읽기 폭은 최대 660px 유지. 나머지 조작/정보는 동일 조건.

주간 좁은 칸/긴 단상/긴 회고/입력/돌아보기 집계 화면 선택, 1100px 및 390/360px 실제 iframe viewport 제공. 축소/transform 없음. 데스크톱 두 화면은 가로 스크롤 또는 A만/B만 전환, 모바일은 원래의 주간 단일 열 흐름 유지. 실제 휴대폰 래스터링/터치 검증을 했다는 의미는 아닙니다.

## 확인한 사실

- 기존 주간은 조선일보명조에 650/700 등을 요청했으며 합성 방지 선언은 없었습니다. 파일에 그 굵기가 없어 브라우저 합성 굵기 개입 가능성이 있습니다. 이전 사용자 화면의 실제 합성 여부는 직접 확인하지 않았습니다.
- 비교본 전체 font-synthesis:none, 단일 명조는 400 정자체. Pretendard는 제공되는 400/500/600 사용. 지원되지 않는 명조 굵기를 합성해 위계를 만들지 않습니다.
- 공개 CDN의 실제 WOFF를 임시 폴더에 받아 테이블을 검사했습니다. 조선일보명조 Regular/weight 400/fvar 없음/version 001.400/442,644 bytes. 리디바탕 Regular/weight 400/fvar 없음/Version 1.0/724,448 bytes. 해시/메타데이터: work/typography-font-metadata.json. 파일 크기는 브라우저의 전송 속도 실측이 아닙니다.
- 폰트 바이너리를 저장소에 추가하거나 글리프/라이선스를 수정하지 않았습니다. 무료 웹폰트 사용을 변환본 우려로 중단시키지 않습니다.
- 지면 #f5f5f3/본문 #252526 및 보조 글자 #595957의 대비를 각각 14.03:1, 6.43:1로 계산 확인. 대비 계산은 실제 글자 굵기/전체 화면의 접근성 검증과 별개입니다.
- 두 후보 × 5개 화면 모의 DOM 초기화 점검 통과: 동일 원문, 긴 글/입력 마크업, 7개 지표/근거, 독립 저장. 스크립트 구문 검사 통과. 실제 브라우저 QA와 구분합니다.

## 직접 렌더링 결과와 미확인

현재 직접 렌더링 확인 결과 없음. 이전 로컬 파일 브라우저 접근 제한을 우회하지 않았습니다. 이번 결과를 직접 렌더링한 데스크톱/모바일 화면이라고 설명하지 않습니다.

후보 하단의 진단은 사용자 브라우저에서 FontFaceSet.load 및 computed style(가족/크기/굵기/행간/자간/합성), viewport/문서 가로 넘침을 보여줍니다. 이번 작업 중 해당 결과를 직접 수집하지 않았습니다. 요청 face 로딩 성공은 모든 글리프의 실제 사용/전체 가독성을 증명하지 않습니다.

## 디자인 의견과 추천

추천 가설 A. 조선일보명조를 큰 제목과 긴 기록에 유지하고 작은 목록/조작/숫자는 Pretendard로 해결하는 것을 먼저 봅니다. 작은 크기·낮은 대비·빽빽한 행간·좁은 칼럼 문제를 서체 탓으로만 판단하지 않습니다.

B의 필요는 명조 분위기를 유지하는 긴 글 읽기에만 있습니다. 리디 제작사는 속 공간/획/모바일·전자책 긴 문장에 맞춘 설계를 설명합니다. 제작 의도이지 이 서비스의 실측 우위가 아닙니다. A의 크기/행간 조정으로 충분하면 추가 서체는 불필요합니다. B는 네 번째 가족의 관리·로딩과 추가 파일이 생기는 대안입니다.
