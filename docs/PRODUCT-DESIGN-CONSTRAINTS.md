# 제품·디자인 제약 — 현행 기준

요약: 승인한 기록 관계와 화면 흐름을 유지하고 과제 필수 기능을 함께 구현합니다. 기능 02.39·디자인 05 기준이며 구현 완료 목록이 아닙니다.

## 범위와 권한

- 계획 → 일정/실행 → 하루 마무리 → 돌아보기. 계획·할 일·루틴·단상·회고·보관함/휴지통·내보내기를 구현합니다.
- T06은 서버 DB 기반 공개 단일 다이어리입니다. 링크를 아는 사람의 동일 자료 열람·편집을 개인별 보호로 설명하지 않습니다. 첫 화면 공개 안내를 유지합니다.
- 회원 인증/소유권과 자동 영구 삭제는 T07 범위입니다. T06 휴지통은 복원 가능하며 자동 만료하지 않습니다.
- 챌린지·새 협업 기능·AI 자동 회고 작성은 추가하지 않습니다. 미완성 화면을 일괄 삭제하지 않고 관련 기능 통합 여부를 검토합니다.
- [과제 RULE](T06-ASSIGNMENT-RULE.md)은 더미 허용 예외만 반영합니다. 원문 조건/외부 평가 기준을 바꿨다고 설명하지 않습니다. C26/C31/C33 및 실제 DB 저장·최소 자료·근거·내보내기는 유지합니다.

## 기록의 이름과 관계

| 이름 | 역할 |
|---|---|
| 단상 | 실제 실행한 할 일 + 선택 날짜별 하나. 계획에는 작성하지 않음. 없는 경우 작성창, 저장된 글은 간결하게 표시 |
| 회고 | 계획에 속하지 않는 날짜별 독립 기록. 하루 마무리에서 선택한 단상을 가져와 직접 수정. 생략 가능, 빈 회고 생성 안 함 |
| 책갈피 | 회고에만 적용. 단상에는 없음. 회고 모음에서 아이콘으로 지정/해제·필터 |
| 막힌 이유 | 실행 기록의 선택 입력. 단상과 별개이며 실행 저장/수정/종료 때 함께 저장. 자동 저장·단상 자동 복사 아님 |
| 개선점 | 돌아보기의 계획 결과에서 다음 계획으로 전달하는 문장. 회고를 계획에 붙이는 기능과 별개 |

## 화면과 조작

- 일정 상세의 예정 시간/실행 기록/단상은 첫 선택 시 모두 접힙니다. 완료 토글로 사용자의 접힘 상태·초안·시선 위치를 초기화하지 않습니다. 상세에서도 완료 체크가 가능합니다.
- 기록 시작은 주요 행동, 계획 배치/실행 기록 입력은 보조 행동입니다. 기록 시작 기본 크기는 이전 기준의 80%입니다.
- 완료하면 같은 할 일의 열린 기록도 함께 종료합니다. 완료 상태에서는 타이머 시작/새 배치/배치 수정 금지, 수기 종료 실행 입력·정정 및 단상 허용. 자세한 원자성은 데이터 계약을 따릅니다.
- 작은 종이색 300px 두 줄 기록 표시: 손잡이/상태·경과 분/기록으로, 제목/멈춤·종료. 펼치기 없음. 드래그·방향키·위치 기억·화면 안전 영역을 유지합니다. 일간 현재 기록과 중복 표시하지 않습니다.
- 주간은 예정/실제/마감이 구분된 점 목록. 시간·우선순위 유지, 각 목록 기본 최대 3개와 남은 개수 안내, 한 번에 한 날짜만 펼침. 칸별 내부 스크롤·좁은 노란 호버·할 일 사이 점선을 피합니다.
- 돌아보기는 계획 결과와 날짜별 시간 사용입니다. 7일 막대/주 합계/선택 하루 상세는 일정 주간의 할 일 나열과 역할이 다릅니다. 큰 날짜 범위는 설명 아래·합계 위입니다.
- 보관함은 회고 모음/휴지통 두 탭. 돌아보기와 같은 위치·크기·간격의 왼쪽 메뉴, 탭 선택으로 자동 스크롤하지 않습니다. 회고 목록을 돌아보기에 중복 배치하지 않습니다.
- 회고 모음은 전체가 기본이며 별도 전체 버튼 없음. 날짜+긴 검색창+우측 끝 책갈피 필터, 초기화 버튼 없음. 공통 캘린더 아이콘 유지.
- 회고 수정은 해당 글 안에서 처리합니다. ⋯의 수정/삭제는 가로 팝오버로 열고 주변 글을 밀지 않습니다. 책갈피 아이콘에 상자를 씌우지 않습니다.
- 회고 본문/날짜 선택은 해당 날짜 일간으로 이동합니다. 출처 계획이 삭제돼도 날짜 이동을 막지 않습니다. 직접 삭제된 계획/할 일을 여는 경우만 해당 자료 상태를 안내합니다.
- 하루 마무리는 오늘 마감 미완료 목록부터 보여줍니다. 불필요한 단계/관련 계획 선택 제거, 회고 작성 버튼 우측 배치와 중복 시작 버튼 숨김. 기존 힌트에 회고 생략 가능 안내 추가. 마무리 후 현재 위치에서 결과를 안내합니다.
- 달력/시간 선택기 스타일·선택기 화살표 안쪽 여백을 통일합니다. 수기 구간은 직접 HH:mm 입력/공통 시계/짧은 시간 보조 버튼을 사용하며 긴 분 단위 드롭다운은 폐기합니다.

## 정보·자료 보호

루틴 일별 발생을 일반 계획 결과의 할 일 수에 중복 넣지 않습니다. 루틴 실제 시간은 일정/시간 사용에서 보존합니다. 집계와 근거는 같은 대상·기간·계산식입니다. 계획 예상 선언값과 할 일 예상 합계를 합치거나 서로 덮어쓰지 않습니다. 계획 우선순위·할 일 태그는 필수 항목입니다.

삭제된 계획/할 일의 실제 실행·단상·회고와 출처 이름은 보존합니다. 수정 전 값도 남기며 복원 충돌을 자동 덮어쓰지 않습니다. 저장 성공은 서버 응답 후 표시하고 실패·충돌에는 입력을 유지합니다.

## 승인 디자인

조선일보명조 400: 메뉴·주요 제목·사용자 서술 기록/그 편집창. Pretendard: 버튼·보조 설명·상태·작은 라벨·기본 숫자. 영문 제호 Cormorant Garamond 500 정자, 총 3가족. 손글씨/Noto Serif KR/리디바탕 추가 없음.

일간 날짜 C안은 요일 세리프·숫자 산세리프. 돌아보기 큰 날짜 범위는 세리프. 다른 숫자 일괄 세리프 변경은 승인하지 않았습니다. 선택 지표는 버건디 #75444b 펜 선(주 1.6/보조 .8). 무채색 종이/잉크·노란 포인트 유지, 넓은 여백과 드문 가는 선. 계획/돌아보기/보관함 최대 940px, 내부 왼쪽 정렬. 특정 작품 재현·갈색 일색·과한 질감·귀여운 스크랩북·회전 콘텐츠는 피합니다.

상세 역할/굵기/라이선스는 [승인 디자인](design/DESIGN-BASELINE.md)을 따릅니다. 사용자 시안 승인과 실제 앱/모바일/글리프 검증은 별개입니다.

## 검토 원칙

이미 승인한 가역적 작업은 반복 승인 없이 진행합니다. 새 제품 정책·비용·공개 범위 변경은 구체 결과로 확인합니다. 과제 충돌은 구현 전에 번호·영향·준수 대안을 알립니다. 문구의 조사·띄어쓰기·용어도 점검합니다.
