# 2026-09-30 합의 UI 운영 반영

## 요약

9월 29~30일 `/study`에서 검토하고 승인한 화면 변경만 기존 React 컴포넌트에 적용해 `https://haruleaf.com/`에 배포했다. 일간 7일 날짜 띠의 의미가 불명확한 배치 표시 점은 제거했다. 날짜 제목 옆 `오늘` 버튼의 구분 점은 승인된 디자인이므로 유지했다. 운영 DB 구조와 사용자 자료는 바꾸지 않았다.

## 적용 범위

- 기존 일정·계획·돌아보기·보관함 컴포넌트의 `study` 분기를 운영 화면에서 활성화했다. `JournalProvider`의 미리보기 모드는 활성화하지 않아 운영 화면은 기존 Supabase 저장 경로를 사용한다.
- 상단 메뉴와 일정 보기 선택기, 계획의 생성·선택·검색 위계, 일간의 계획별 접힘, 돌아보기 근거와 선택 메뉴, 보관함 회고 미리보기, 삭제 확인창 등 승인한 `/study` UI를 반영했다.
- 일간의 날짜 제목은 기존 서체와 형식을 유지하면서 이전/다음 화살표, 기존 달력 아이콘, 채택한 `오늘` 이동 버튼을 사용한다. 날짜 띠의 배치 표시 점만 삭제했다.
- 일간의 `할 일 찾기`는 데스크톱·좁은 화면 모두에서 제거했다. 계획 화면의 검색 기능은 유지한다.
- `/study` 비교 페이지와 고정 예시 자료는 운영 정적 빌드에 포함하지 않았다.
- 타임라인·할 일 상세·주간·월간의 원래 구성, 사용자가 지정한 기존 서체·색·아이콘과 정보 구조는 이번 배포에서 새로 설계하지 않았다.

- 주요 적용 파일: `web/src/app/page.tsx`, `web/src/components/journal-app.tsx`, `web/src/components/schedule.tsx`, 기존 컴포넌트의 승인 시안 분기, `web/src/app/study/study.css`.
- 기존 테스트 75건, TypeScript 검사, 정적 빌드 및 정적 결과 확인을 통과했다.
- 운영 릴리스: `/opt/haru-web/releases/t07-ui-e3d03e4`. 배포 파일 SHA-256: `e3d03e4d6233f23f6397757cdd3c54880497468097ad161383f15327fbbeedd0`.
- 웹 컨테이너가 새 릴리스 파일을 읽고 `healthy` 상태인 것을 확인했다. 로그인된 운영 화면에서 기존 기록(일간 14/16 완료), 상단 메뉴, 일간 날짜 띠, 계획별 접힘을 확인했다. 일간 검색 요소와 날짜 띠 점은 각각 0개였다.
- 복귀 가능한 직전 운영 릴리스는 `/opt/haru-web/releases/t07-ui-9340a2a`이다.

## 확인 한계

배포 점검 중 실제 계정의 계획·할 일·실행 기록을 새로 저장하거나 삭제하지 않았다. 따라서 이 릴리스의 모든 저장 조작에 대한 운영 DB 쓰기 시험을 완료했다고 주장하지 않는다. 기존 인증·저장 경로는 유지된다.
