# T07 제출 이후에 다시 다룰 일

요약: 사용자가 2026-09-30에 PDF 출력을 T07 과제 제출 이후로 미루기로 결정했다. T07 제출 완료가 확인되면 이 항목을 다시 언급하고, 출시용 제품의 요구사항·정보 구조를 먼저 검토한다.

## PDF 출력

- 현재 계정의 `내 기록 내보내기`는 전체 자료를 JSON 파일 하나로 내려받는다. T06-C36과 T07-C133은 전체 자료의 한 파일 내보내기를 요구하지만 JSON 또는 PDF 확장자를 지정하지 않는다.
- 이전 [요구사항 초안](../archive/planning/requirements-v1.md)은 전체 자료 JSON 백업과 기간별 요약 PDF를 별개로 구분했다. PDF는 아직 구현되지 않았다.
- **진행 시점: T07 과제 제출 후.** 제출 전에 JSON을 PDF로 대체하거나 과제 범위를 늘리지 않는다. 제출 완료를 사용자가 알리면 PDF 건을 다시 언급한다.
- 그때 사용자가 원하는 읽기·인쇄용 범위와 출력 위치를 다시 결정한다. 기존 JSON 전체 내보내기는 자료 보관용으로 유지할지 함께 검토한다. 옛 PDF 구성 초안을 최종 승인안으로 간주하지 않는다.

## 출시 방향

과제 제출 이후 사용자는 웹 서비스를 원하는 방식으로 개선하고 향후 Windows·macOS 프로그램과 휴대폰 앱으로 확장하기를 원한다. 각 플랫폼의 화면·기능·일정은 아직 확정하지 않았다. 현재 웹의 미승인 디자인을 임의로 변경하는 근거로 사용하지 않는다.
