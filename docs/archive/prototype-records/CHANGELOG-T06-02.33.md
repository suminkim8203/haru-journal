# 02.33 일간 상세·시간 분류·무채색 정리

요약: 일간 상세의 초기 밀도와 완료 체크 깜박임을 줄이고, 시간 사용 화면·목록 접기 아이콘·색감을 정리했습니다. 실제 앱 변경과 구분합니다.

- 예정 시간/실행 기록/단상 기본 접힘, 단상 접기·펼치기. 재선택 시 닫힘, 완료 체크 시 펼침 상태 유지.
- 목록 접기 버튼: 네모 테두리 제거, 목록과 방향 화살표 SVG 및 접근성 이름.
- 시간 사용: 작업/휴식/중단 세 분류, 과거 pause를 interrupt에 합산. 대각선 별도 분류 표시 제거. 내부 기록/경계/이력 보존.
- 큰 MM.DD–MM.DD 범위를 설명 아래·합계 위에 표시. 기록 편집 선택기/휴식·중단 미리보기도 동일 분류.
- 바탕/선/글씨 무채색 정리, 노란색 등 포인트색과 기존 서체 유지.
- 일간 완료 저장은 전체 render 대신 기존 체크박스·행 상태·완료 수만 갱신. 중복 방지/실패 되돌림/충돌 안내/재시도 유지.

검증: work/test-v233.cjs, work/test-v233-regression.cjs 통과. 저장 전후 전체 재그리기 없음·즉시 체크 동기화·완료 수·포커스/스크롤/접힘/작성 중 단상 보존·실패/충돌/재시도, 분류 합산 및 시간 보존, 달력/그래프/주간 목록/기록 표시 회귀 확인. DOM을 모의한 코드/마크업 검사이며 실제 브라우저 시각·터치 검증은 미완료입니다.

React 앱/서버 DB는 변경하지 않았습니다. 과제 C26/C31/C33 최소 복원안은 결정 대기이며 자동 복원하지 않았습니다. 다음은 이번 화면 검토 후 과제 충돌 해결 및 전체 앱 구현입니다.
