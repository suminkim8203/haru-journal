# 02.36 — 막힌 이유 저장 안내·단상 표시 보정

요약: 나머지 보정 화면 승인 후 저장 안내와 단상 중복 표시 경로를 수정했습니다. 실제 앱/API/SQL은 이번에 변경하지 않았습니다.

- 막힌 이유는 자동 저장하지 않으며 실행 기록 저장/변경 저장 또는 기록 종료로 함께 저장. 입력란에 안내 추가. 기존 실행 저장 버튼은 하단 고정 표시, 추가 저장 버튼 없음.
- 실행 기록 입력의 구형 단상 textarea 제거. 실행 수정은 기존 note/이력 보존, 새 실행에서 별도 단상 복제 없음.
- 막힘 근거에서 구형 run.note 단상 반복 표시 제거, 실행 이유/시간 근거 유지.
- 날짜별 단상 합칠 때 동일 내용 복수 출처는 한 번 표시하고 memberIds는 모두 보존. 원문 자료 자동 변경/삭제 없음. 일정 할 일 수정창의 두 번째 단상 표시 제거.
- 비교 화면은 Haru-required-flow-study-02.html, 전체는 T06-flow-v2.36.html. 기존 비교 화면/본 시안은 보존.

검증: 스크립트 구문 검사, 기존 15개 런타임/마크업 점검, 추가 명시적 저장/구형 단상 입력 제거/동일 출처 표시 통합·원문 보존/이유 근거/할 일 수정창 분리 점검 통과. 사용자 기존 자료에서 동일 현상을 실제 브라우저로 재현한 결과는 현재 확인되지 않음. 모의 DOM 확인은 시각/모바일 검증이 아님. 잔여 완료 체크 깜박임은 계속 실제 앱 재현 단계로 보류.

과제 C26/C31/C33/C04 및 관련 C08/C27/C83 보정 유지. 실제 DB 저장/복원·배포/제출 검증 완료를 의미하지 않음. 다음은 승인 계약의 실제 앱/API/SQL 구현.
