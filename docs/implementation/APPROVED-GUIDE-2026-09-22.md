# 승인 필기 안내·밑줄 적용

요약: release approved-50c0038302f8을 공개 서비스에 배포했다. 이전 approved-239429c65e97 유지/롤백 가능. DB 변경 없음.

## 적용

주요 메뉴 오른쪽 사용 안내 → 예시 기반 안내를 dialog/iframe으로 제공. 승인 시안10의 손글씨(대광유리)/숫자(소방관의 기도), 원본 파란 동그라미, 문장별 줄바꿈, 이전/다음/건너뛰기를 유지한다. 예시 데이터는 안내 메모리에만 저장하며 서버 호출 없음. 닫으면 기존 앱 상태로 돌아온다. 제품 코드: web/src/components/usage-guide.tsx, journal-app.tsx. 안내 파일: web/public/guide/index.html.

돌아보기 선택 숫자 아래 붉은 원본 펜자국 적용. 필터 외곽 사각형은 SourceGraphic 합성으로 수정. 숫자의 기존 세로 배치 유지. ink-underline.tsx, review.tsx, globals.css.

## 검증

정적 빌드/타입 검사 통과, 기존 테스트 55/55 통과. 브라우저 데스크톱·390px 모바일에서 입력 없이 7/7 진행 확인, 건너뛰기 dialog 닫힘/포커스 복귀 확인. 대광유리 computed font-family 확인, 실제 모바일 렌더링 확인. 원본 밑줄 브라우저 확인. 공개 앱 사용 안내 진입 확인. 공개 정적 파일 27개 SHA-256 일치.

NAS nginx 설정/기존 이미지/라우터 보존, 내부·공개 HTML 일치, DB 미변경. 배포 스크립트 성공 화면 확인. [파일 검증](../deployment/guide-public-verification-2026-09-22.json).

## 남은 범위

현재 T06 공개 앱에 수동 사용 안내를 추가한 상태. 가입 후 자동 실행/계정별 완료 상태/인증 자체는 T07 미구현. 안내는 실제 사용자 자료 위에서 편집을 유도하는 화면이 아니라 승인한 예시 흐름이며, 제품 자료는 변경하지 않는다. 서버 격리/메일 인증 구현 후 자동 진입 연결 예정.

폰트 사용 기준: 네이버 공식 https://hangeul.naver.com/font 에서 클로바 나눔손글씨의 상업 사용/오픈 라이선스 안내 확인. 지정 CDN 웹폰트 유지; 폰트 바이너리 재배포하지 않음.
