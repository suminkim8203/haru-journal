## 동일 계산 규칙

1. 종료된 실행 기록의 각 `work` 구간을 Asia/Seoul 날짜 경계에서 자르고 해당 날짜의 초로 더한다. 동일한 실행 기록 ID는 한 번만 센다.
2. 실제 작업 기록이 빠졌다면 해당 날짜를 `미기록`으로 표시하고 평균의 0분으로 대체하지 않는다. 앱을 사용했으나 실제 작업 시간이 0분인 날은 그 사실을 확인할 수 있는 기록이 있을 때만 0분으로 기록한다.
3. 수기 기록과 타이머 기록이 같은 시간을 중복으로 나타내는지 점검한다. 중복이 확인되면 원본 이력을 보존한 채 정정하고 최종 집계에는 한 번만 반영한다. 겹침이 해소되지 않으면 중복 가능성을 명시하고 결과를 확정하지 않는다.
4. 유난히 큰 값도 임의로 제외하거나 상한을 씌우지 않는다. 기록 오류인지 확인해 수정 이력을 남기고, 실제 긴 작업이면 이유와 함께 그대로 포함한다.
5. 초 단위 원값으로 합계·평균을 계산한 뒤 표시할 때만 분 단위 소수 첫째 자리로 반올림한다. 변경 전 2일 평균과 변경 후 3일 평균에도 같은 규칙을 적용한다.
6. 앱 화면의 해당 날짜 작업 합계와 원자료를 손으로 더한 값을 대조한다. 다섯 날짜의 총합·평균을 별도로 화면과 대조할 방법은 실제 기록이 쌓인 뒤 마련한다. 화면에 없는 합계·평균을 이미 검증했다고 적지 않는다.
