## 기준과 보존

- 기준 파일: `T06-flow-v2.7.html`
- 새 파일: `T06-flow-v2.8.html`

- 작업 전 원본과 보존한 02.7의 SHA-256이 같습니다.
- 02.8은 별도 브라우저 저장 키를 사용하여 02.7의 프로토타입 상태와 섞이지 않습니다.

## 현재 02.8 프로토타입에 실제 반영된 기능

### 일정·일간 계획/할 일 목록

- 데스크톱 왼쪽에 접고 펼칠 수 있는 계획별 할 일 목록을 추가했습니다.
- 계획 폴더마다 `완료 수 / 전체 수`를 표시합니다.
- 할 일 체크박스에서 완료와 완료 취소를 처리합니다.
- 할 일 제목을 선택하면 해당 할 일의 시간·기록 상세가 열립니다.
- 할 일 수정용 `⋯`는 데스크톱에서 hover, 키보드 focus, 현재 선택 상태일 때 표시합니다.
- 모바일에서는 `⋯`를 항상 탭할 수 있습니다.

### 선택한 할 일의 시간·기록 상세

- 완료와 기본 정보 수정 액션을 상세에서 제거했습니다.
- 오늘의 기록 전 상태에서는 `기록 시작`, `시간 관리`를 제공합니다.
- 기록 중에는 `잠시 멈춤` 또는 `다시 시작`, `기록 종료`만 제공합니다.
- 기록 종료는 실행 기록만 저장하며 할 일 완료 상태를 변경하지 않습니다.
- 시간 관리 내부를 다음 네 구역으로 분리했습니다.
  - 기존 배치 확인·수정·삭제
  - 시간 추가 배치
  - 직접 실행 기록 입력
  - 기존 실행 기록 확인·정정

### 계획·할 일 화면

- 선택한 할 일 행의 기본 액션을 `수정` 하나로 정리했습니다.
- 기록 시작 액션을 제거했습니다.
- 할 일 수정 화면을 `기본 정보`, `시간 배치`, `실행 기록`으로 구분했습니다.
- 완료 처리는 기존 행 체크박스를 유지합니다.

### 드래그 시간 배치

- 데스크톱의 정밀 포인터 환경에서 할 일 제목을 계획 타임라인으로 끌 수 있습니다.
- 위치는 15분 단위로 맞춥니다.
- 기본 블록 길이는 할 일 예상 시간입니다. 예상 시간이 없으면 15분을 사용합니다.
- 끄는 동안 계획 레인에 미리보기 블록을 표시합니다.
- 타임라인 위·아래 가장자리에서는 필요한 방향으로 자동 스크롤합니다.
- 놓은 직후 저장하지 않고 시작 시각, 배치 시간, 예정 종료를 표시합니다.
- `배치`를 선택해야 예정 시간이 추가됩니다.
- 기존 배치와 겹치면 경고와 `겹쳐서 배치 확인`을 요구합니다.
- 블록 크기 조절은 이번 범위에서 제외했습니다.

### 모바일·키보드 대체 흐름

- 모바일에서는 사이드바 대신 `오늘 할 일 n / m` 접이식 목록을 제공합니다.
- 드래그는 모바일과 키보드 환경에서 필수가 아닙니다.
- 시간 관리의 명시적 `시간 배치`와 `시간 추가 배치` 흐름을 유지합니다.

### 02.7에서 유지한 기능

- 수동 실행 기록 추가와 기존 실행 기록 정정
- 종료 시각, 실행 범위, 휴식·중단 중복, 기존 실행 기록 겹침 검증
- 주간 전체 요약과 월간 달력
- 날짜 선택기와 12시간제 시각 선택기
- 예정·실제 시간 비례 블록과 짧은 블록 표시
- 기록 수정 이력, 검토용 실패·시간 경과 도구

## 구현하지 않은 기능

- 타임라인 블록 resize
- 모바일 drag & drop
- 서버 DB 저장, 인증, 계정 간 동기화
- 실제 알림, 백그라운드 타이머 서비스, 다중 사용자 충돌 처리

## 서비스가 지원하지만 현재 사용하지 않는 기능

- 브라우저는 HTML5 drag & drop, 서버 통신, 원격 저장을 지원할 수 있으나 이 시안은 로컬 프로토타입 상태 변화만 사용합니다.
- 외부 데이터베이스·호스팅·인증 서비스는 연결하지 않았습니다.

## 확인이 필요한 불확실한 부분

- 실물 모바일 기기의 터치 조작감은 현재 확인되지 않았습니다.
- 자동 브라우저 도구가 로컬 `file:` URL을 열지 못해 실제 포인터 drag 이벤트와 화면별 시각 배치는 자동 브라우저에서 확인되지 않았습니다.
- 검토 시에는 데스크톱에서 드래그 위치 정확도, 클릭과 드래그의 충돌 여부, 740px 전후 타임라인 폭을 우선 확인해야 합니다.
