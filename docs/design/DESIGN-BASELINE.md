# 승인 디자인 기준 — 시안 05

요약: 조선일보명조를 중심으로 고전 출판물·개인 기록장의 인상을 유지하되 조작과 작은 정보는 Pretendard로 읽기 쉽게 구분합니다. 2026-09-18 사용자 승인.

## 서체 역할

| 요소 | 서체 | 규칙 |
|---|---|---|
| 영문 제호 | Cormorant Garamond 500 | 정자, 기울이지 않음 |
| 주요 메뉴·보기 전환·하위 페이지 메뉴 | 조선일보명조 400 | 작아도 세리프. 버튼과 구별 |
| 페이지·큰 섹션·계획·할 일 제목 | 조선일보명조 400 | 역할로 분류. 좁은 주간 칸도 제목 유지 |
| 일반 버튼·검색·필터·라벨 | Pretendard | 조작과 실무 정보 |
| 보조 설명·상태·날짜·시간·기본 숫자 | Pretendard | 대비·크기·밀도도 함께 검토 |
| 단상/실행 기록 등 작은 펼침 라벨 | Pretendard | 큰 섹션 제목과 구별 |
| 사용자 서술 기록·그 기록의 입력창 | 조선일보명조 400 | 단상·회고·이유·서술형 상세. 본문과 입력 역할 일치 |

총 3가족. Noto Serif KR·리디바탕·손글씨는 현행 적용에 사용하지 않습니다. 단일 굵기 명조를 브라우저 합성 bold로 처리하지 않으며 실제 글리프와 로딩 확인을 선언 검사와 구분합니다. 상세 매핑·라이선스·지원 굵기는 [승인 역할 규칙](TYPOGRAPHY-APPROVED-ROLES.md)과 [서체 사용 기록](FONT-USAGE.md)을 따릅니다.

## 승인 날짜 예외와 선

- 일간 일~토: 요일은 조선일보명조, 숫자·작은 ‘오늘’은 Pretendard(C안). 기존 크기와 간격 유지.
- 돌아보기 날짜별 시간 사용의 큰 월.일–월.일: 제목 역할의 조선일보명조 400.
- 그 외 주간/월간/캘린더/집계 숫자를 일괄 세리프로 바꾸자는 내용은 미확정 고민이며 임의 적용하지 않음.
- 계획 결과 선택 지표: 바랜 버건디 #75444b, 펜 곡선 주 획 1.6(기존 2.2), 보조 획 .8. 기능·선택 영역 유지.

## 지면과 구조

넓은 여백·제목 크기 차·드문 가는 구획선으로 위계를 만듭니다. 무채색 종이와 검은 잉크 중심, 노란 선택 강조는 유지하며 버건디는 작은 강조에 제한합니다. 종이 질감은 매우 약하게, 손글씨/갈색 일색/찢은 종이·얼룩/기울인 콘텐츠·불규칙 조작 배치는 사용하지 않습니다. 특정 작품 로고나 소품을 재현하지 않습니다. 따뜻한형은 폐기했습니다.

계획/돌아보기/보관함 최대 콘텐츠 폭 940px, 콘텐츠 내부 왼쪽 정렬. 일정의 넓은 타임라인/주간 구조는 유지합니다. 보관함 탭 위치·크기·간격은 돌아보기와 동일합니다. 필수 정보·집계·근거·공개 안내를 삭제해서 분위기를 만들지 않습니다.

기록 표시: 승인된 300px 두 줄 종이색 패널·드래그·안전 영역·방향키·위치 기억, 펼치기 제거. [기록 표시 검토](RECORDING-UI-STUDY.md) 참조. 일반 UI 선호 저장과 실제 사용자 자료 DB 저장은 별개입니다.

## 적용과 검증

승인 결과는 HTML 디자인 검토본에 반영된 상태입니다. React 전체 앱에 적용 완료가 아닙니다. 사용자는 시안 05의 외관을 승인했습니다. 자동 실제 브라우저/모바일/서체 렌더링 점검은 미완료이며, 과거 모의 DOM 기능 검사와 구분합니다.
