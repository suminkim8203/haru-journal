# T06 02.12 — 삭제와 복원

한 줄 요약: 수정 화면에서 할 일 또는 루틴을 휴지통으로 이동하고 복원할 수 있도록 구현했으며, 실제 실행 기록은 유지합니다.

## 현재 프로젝트에 실제 구현된 기능

- 일반 할 일 수정 화면 맨 아래 별도 삭제 구역. 저장 버튼과 분리합니다.
- 루틴 규칙 수정 화면의 루틴 삭제. 변경할 미래 날짜가 없는 루틴도 관리 화면에서 삭제할 수 있습니다.
- 확인 후 휴지통 이동. 확인 취소 시 입력 초안과 자료를 유지합니다.
- 일반 할 일: 해당 항목과 활성 예정 배치를 숨깁니다.
- 루틴: 반복 규칙과 소속 날짜별 항목 전체를 숨깁니다. 과거·완료·개별 수정 항목도 포함한다고 확인 화면에 명시합니다. 하루만 제외하는 기능은 기존 건너뛰기를 사용합니다.
- 실행 중인 기록이 하나라도 포함되면 기록 종료 전 삭제를 차단합니다.
- 종료한 실행 기록은 삭제하지 않습니다. 삭제된 할 일의 제목을 해석할 수 있도록 내부 참조를 보존하며, 돌아보기의 날짜별 시간 사용에 계속 포함합니다.
- 삭제된 항목은 새 기록·예정 배치·완료 변경을 막고, 기존 실행 기록 확인·정정은 허용합니다.
- 설정 → 휴지통에서 복원 및 보존한 기록 보기가 가능합니다.
- 복원은 원래 식별자·완료·건너뛰기·개별 수정 상태를 유지합니다. 실행 기록을 복제하지 않습니다.
- 복원할 예정 배치가 현재 일정과 겹치면 겹침 허용 확인을 거칩니다.
- 삭제·복원은 프로토타입의 저장 실패/다른 창 충돌 점검 경로를 사용합니다.

## 구현되지 않은 기능

영구 삭제, 자동 보관 기간, 삭제된 계획 복원, 서버 휴지통·권한은 추가하지 않았습니다. 부모 계획 자체 삭제도 이번 범위 밖입니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서버/DB 연결 없음. 브라우저 안의 모의 저장입니다.

## 확인이 필요한 부분

- 실제 클릭·모바일 레이아웃·확인 팝업의 읽기 쉬움은 미검증입니다.
- 계획 결과 지표는 현재 활성 할 일을 기준으로 하므로 삭제 항목을 제외합니다. 실제 활동 이력은 날짜별 시간 사용에서 보존합니다. 두 집계의 기준은 다릅니다.
- 루틴 삭제는 이후 반복 중단과 달리 소속 날짜별 항목 전체를 휴지통으로 이동합니다. 실행 기록 자체는 삭제하지 않습니다.

## 보존

02.11.1과 이전 결과 파일은 변경하지 않았습니다. 별도 `t06.pds.flow0212.*` 저장 키를 사용하며, 첫 실행에서 접근 가능한 이전 자료를 한 번 복사합니다. 이전 저장값은 덮어쓰지 않습니다. 로컬 파일별 저장소가 분리되는 브라우저에서는 복사가 불가능할 수 있습니다.
