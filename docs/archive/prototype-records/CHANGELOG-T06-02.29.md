# 02.29 보관함 메뉴 위치 및 콘텐츠 폭

- 02.28의 보관함 메뉴는 nav 전역 규칙으로 중앙 정렬되는 오류가 있었습니다. 돌아보기와 같은 div/button 구조를 사용해 해당 전역 규칙을 받지 않게 했습니다.
- 공통 review-tabs CSS로 높이·글자 크기·간격·패딩·하단 활성선을 공유합니다. 메뉴는 콘텐츠 왼쪽 끝에 정렬합니다.
- 계획/보관함(휴지통 포함)의 제목·도구·본문·알림을 최대 940px 열에 중앙 배치합니다. 돌아보기 폭과 동일합니다. 좁은 화면에서는 기존 여백 안의 가용 폭을 사용합니다.
- 서체와 서비스 자료·저장 키·이벤트 동작은 유지합니다.
- 검증: 기존 런타임 검사 도구에서 회고 모음/휴지통 최종 메뉴 HTML 확인, 돌아보기와 구조 공유 확인, 940px CSS 확인, 전체 JS 구문 검사 통과.
- 미확인: 실제 브라우저 픽셀/모바일 시각 검사.
- 다음: 사용자 화면 검토 후 승인된 폭·서체·메뉴 규칙을 React 구현에 적용합니다.
