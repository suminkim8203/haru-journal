# 02.20 변경 기록

시간선 오류 수정, 상세 완료 체크, 날짜별 메모 → 독립 일기, 통합 보관함을 반영했습니다. 기존 02.18 파일은 보존했습니다. 02.19로 예정한 수정은 이번 버전에 통합했습니다.

- 시간선: 매초 위치 갱신 및 탭 복귀/창 초점 복귀 갱신. 이른 시간 펼침·자정 이후 일정 표시 범위 반영. 타이머 저장 자료는 변경하지 않습니다.
- 상세 완료: 목록과 동일 상태를 수정합니다. 실행 기록은 종료하지 않습니다.
- 짧은 메모: 계획/할 일의 날짜별 입력·수정·삭제·복원. 기존 설명과 구분됩니다.
- 회고: 일기 중심 카드, 메모 선택 가져오기, 독립 저장, ⋯ 수정/삭제.
- 책갈피: 전체 일기를 팝업 없이 저장, 중복 방지, 일시 알림 보기 및 보관함 고정 진입.
- 보관함: 회고 모음·책갈피·휴지통. 저장한 일기를 검색/날짜/계획으로 다시 찾습니다.
- 계획에 붙이기: 사용자 진입과 새 저장 동작을 차단합니다. 기존 planMemos 자료는 보존해 읽을 수 있습니다.
- 화면: 일기 제목의 명조와 조작/본문 고딕 역할 구분, 카드/섹션 여백, 상세 이동 스크롤 보강.

자료 기준과 사용 흐름은 ../docs/JOURNAL-DECISIONS-02.20.md에 정리했습니다.

사용자 확인 필요: 실제 시간선 이동, 메모에서 일기 작성, 보관함에서 다시 찾기, 모바일 및 화면 가독성. 아직 사용자 승인을 받은 최종 디자인은 아닙니다.
