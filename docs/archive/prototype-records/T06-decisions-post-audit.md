# T06 과제 대조 후 결정 기록

한 줄 요약: 전체 1~4단계 제안은 루틴 진행률 표시를 제외하고 승인됐습니다. 루틴 지표의 수정 추천안은 아직 확정하지 않습니다. 과제 7 작업은 보류합니다.

## 현재 프로젝트에 실제 구현된 기능

기준 시안은 02.13입니다. 이번 결정 기록으로 HTML·서버·삭제 기능이 변경된 것은 아닙니다.

## 승인된 기획과 미구현 작업

- 일반 계획은 과제 필수 기간·우선순위·성공 기준·예상 시간·이력을 유지합니다. 기간 없는 루틴 묶음은 추가 기능으로 구분합니다.
- 과제 기본 집계는 선택 범위의 삭제하지 않은 할 일을 대상으로 C28~C32 공식을 따릅니다. 건너뛰기·중단이라는 이유만으로 기본 집계에서 제외하지 않습니다.
- 삭제 자료는 30일 휴지통에서 복원할 수 있으며 만료일을 표시합니다.
- 영구 삭제는 선택한 삭제 대상에 속한 실행 기록과 하위 기록까지 삭제합니다. 사용자는 이 범위에 동의했습니다. 30일 만료 처리에도 같은 대상 범위를 적용합니다.
- 하위 범위에는 해당 대상의 예정 배치, 실행 구간, 수정 이력 등 종속 자료를 포함합니다. 공유 사유 목록과 독립 일간 회고 전체처럼 별도 자료까지 연쇄 삭제하는 권한으로 확대하지 않습니다. 연결 메모·발췌의 종속/독립 경계는 DB 설계에 명시합니다.
- 계획 상태·전체 삭제, 사유 관리, 휴지통, 전체 JSON·요약 PDF, 반복 재개·건너뛰기 취소를 세 화면 묶음으로 검토합니다. 각 묶음 확인 후 다음 묶음으로 진행합니다.
- 공개 편집·실제 서버 저장·중복 요청 방지·충돌 처리·과제 기준별 검증·실제 자료 입력·제출 묶음 준비를 진행합니다. 기능의 승인과 구현·검증 완료는 구분합니다.
- 과제 7은 당장 고려하거나 구현하지 않습니다. 기존 준비 파일은 참고용으로 보존하되 이번 작업의 선행 조건으로 삼지 않습니다.

## 루틴 표시 — 사용자 우려와 수정 추천안

사용자는 지나간 날짜의 미진행이 진행률에 누적되면 스트레스를 받을 수 있다고 지적했습니다. 별도 루틴 진행률은 과제 필수가 아닙니다.

추천안(미확정):

1. 루틴 기본 목록에는 오늘 또는 선택한 날짜의 상태만 표시합니다. 누적 백분율, 연속 달성, 미진행 누적 숫자를 전면에 표시하지 않습니다.
2. 날짜별 이력은 사용자가 열 때만 확인합니다. 빠진 날을 자동 이월하거나 벌점으로 만들지 않습니다.
3. 과제 필수 돌아보기에서는 정해진 집계와 근거를 그대로 제공합니다. 스트레스 완화를 이유로 C28~C32 계산을 변경하거나 자료를 숨기지 않습니다.
4. 별도 루틴 진행률 지표 자체는 이번 버전에서 생략하는 것을 추천합니다. 사용자가 필요성을 확인했을 때 재검토합니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스 선택이나 서버 작업은 이번 기록에서 수행하지 않았습니다.

## 확인이 필요한 부분

루틴 표시 추천안만 확인이 필요합니다. 영구 삭제 대상의 기술적 관계와 삭제 검증은 구현 전에 설계하며 실제 사용자 자료를 지금 삭제하지 않습니다. 과제 7 전문은 현재 작업을 막는 조건이 아닙니다.
