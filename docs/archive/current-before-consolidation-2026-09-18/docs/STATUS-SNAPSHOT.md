## 미구현 또는 후속 구현

실제 앱의 전체 일정/시간 배치/타이머/실행·단상·회고/루틴·휴지통/집계와 근거 이동/내보내기 및 승인 디자인 이식은 첫 저장 구현 이후 범위입니다. 자동 삭제·로그인·사용자별 소유권은 T06에 추가하지 않습니다.

Supabase Auth/Realtime/Storage/Edge Functions는 플랫폼 기능이며 컨테이너가 실행된 사실만으로 앱 기능이 구현됐다고 보지 않습니다. Studio 관리자 Basic 인증과 회원가입·초대·이메일 확인·계정 활성화·최초 비밀번호 설정·변경·재설정은 별개이며 후자는 현재 앱 사용자 흐름으로 구현/검증하지 않았습니다.
