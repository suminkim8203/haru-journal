## 02.38 — 완료 상태와 기록·배치 제약

완료 체크는 동일 할 일의 열린 실행도 같은 저장에서 종료합니다. 종료 확인 후보가 있으면 그 시각을 유지하고, 실패 시 완료/종료 모두 반영하지 않으며 재시도 종료 시각을 고정합니다. 완료한 할 일의 타이머 시작/새 배치/배치 수정은 UI와 저장 경로에서 차단합니다. 수기 실행 입력/정정·단상은 유지하며 완료 취소하면 배치/타이머 시작을 다시 허용합니다. 다른 할 일의 열린 실행은 종료하지 않습니다.

휴식/중단 시각은 전체 실행 시작/종료 범위 안의 분 단위 선택기로 제공하며 전체 시각 미입력 시 추가를 막습니다. 부모 시간 변경 후 범위 밖 기존 선택은 자동 덮어쓰기 없이 수정 안내하고 저장 검증을 유지합니다. 자정 넘김은 다음 날로 표시합니다. 펼침 아이콘은 고정 크기 28px SVG로 변경, 기록 시작 기본 버튼 160×52→128×41.6px 및 글씨 17→13.6px. 모바일은 폭 80%를 적용합니다.

검증: 집중 점검 8개, 기존 15개, 공통 달력/주간·시간 차트/플로팅 기록 패널 회귀 점검 통과. 회귀 패널 예시는 완료된 할 일에 열린 기록을 만드는 구형 조건이었으므로 미완료로 수정해 최신 규칙에 맞췄습니다. 브라우저 시각/모바일 검토 및 사용자 실제 자료의 직접 재현은 미완료입니다. HTML 시안/비교 화면에 반영했으며 실제 앱/API/SQL은 변경하지 않았습니다. 다음은 이 계약의 실제 앱/DB 구현입니다.
