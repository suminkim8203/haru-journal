# 02.17 변경 기록

기록 시작을 주 동작으로 강조하고 주간 목록의 호버 영역을 정리했습니다.

- 오늘 선택된 할 일의 기록 시작은 왼쪽 큰 버튼, 계획 배치·실행 기록 입력은 오른쪽 작은 보조 버튼입니다. 좁은 화면에서는 시작 버튼 아래 오른쪽에 보조 버튼이 놓입니다.
- 과거·미래 날짜 또는 다른 기록 진행 중에는 시작 버튼을 숨기지 않고 비활성 상태와 이유를 표시합니다. 현재 기록 자체를 보고 있을 때에는 기존 진행 중 조작 화면을 유지합니다. 할 일 미선택·제외된 루틴은 기존 안내를 유지합니다.
- 주간 점을 버튼 안에 포함해 행 전체를 클릭 대상으로 만들고 호버를 옅은 회색으로 변경했습니다. 예정·실제 구분과 시간·우선순위·완료 정보는 유지합니다.
- 02.16 저장 키를 유지합니다. 실제 파일 간 브라우저 저장소 공유 여부는 확인되지 않았습니다.
- 스크립트 문법 및 모의 환경 검사 11개 통과. 실제 브라우저 배치·호버·모바일은 확인되지 않았습니다.
- 서버·DB·외부 서비스 기능 추가는 없습니다.
