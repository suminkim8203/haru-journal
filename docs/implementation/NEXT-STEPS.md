# 다음 진행

요약: 공개 배포·main 통합·휴대폰 조회·제출문 확인·두 DB 백업/격리 복구·자동 백업에 이어 실제 Ubuntu VM 재부팅 후 자동 복구까지 검증했다. 별도 장비 백업은 아직이다.

1. [백업·격리 복구](../deployment/BACKUP-RESTORE-2026-09-21.md) 및 [정상 VM 재부팅 자동 복구](../deployment/REBOOT-VERIFICATION-2026-09-21.md) 완료. 추가 재부팅이나 재배포는 필요하지 않다.
2. 장비 고장에 대비하려면 같은 NAS 디스크 밖의 백업 장소를 정한다. 별도 장비·외장 저장소·사용 중인 클라우드 등 사용자가 선택한 목적지가 필요하다. 임의 계정 생성·결제·업로드는 하지 않는다. 현재 백업에는 비밀 운영 설정도 들어 있어 외부 전송 전 목적지와 보호 방법을 정해야 한다.
3. [제출 자료](../submission/T06-SUBMISSION.md)는 준비됐다. 외부 과제 제출 자체는 실행하지 않았다. 사용자가 제출처에서 제출할 수 있다.
4. 향후 대량 반복 자료·전체 화면 쓰기 조작·빈 자료/오류 흐름 전수 검증과 외부 백업 실패 알림은 별도 남은 보완이다. 이미 확인한 53개 자동 검사/공개 읽기/실제 DB 검증과 구분한다.
