# 디자인 검토 03 — 부분 복원과 세리프 비교

요약: 상단은 검토 01의 서체, 주간은 디자인 변경 전 02.39의 서체로 복원합니다. 제호 정자체·주요 메뉴의 Noto Serif KR은 유지하고, 선택 밑줄과 월간 이번 달 버튼을 보정합니다. 최종 기본 세리프 선택은 비교 후 결정합니다.

## 적용한 범위

- 최신 검토 HTML: 검토 03（로컬 자료: `../outputs/Haru-design-study-03.html`）. 본 기능 시안 02.39/실제 React 앱/API/DB 미변경.
- 상단 PLAN·DO·SEE, 영문 부제/작은 표기 및 시안/공개 안내는 검토 01의 Pretendard 지정으로 복원. 좌측 한글 문구는 검토 01에서도 Noto Serif KR이므로 그대로 유지. 제호는 Cormorant Garamond 정자체 유지.
- 주요 메뉴 일정/계획/돌아보기/보관함은 Noto Serif KR 유지. 이전 사용자가 세리프를 지정한 메뉴는 이 영역임을 기록.
- 주간 화면은 본 시안 02.39의 조선일보명조체로 복원. 주간 루트의 서체 변수만 덮어써 제목·본문·상태·시간·요일 옆 날짜 숫자도 함께 복원. 구조/크기/정보/행동은 유지.
- 이전의 짧고 기울어진 테두리 밑줄을 두 개의 불균일한 곡선 획으로 교체. 72×12px의 SVG 마스크를 사용해 획 시작/끝은 둥글고, 겹쳐 긋는 얇은 흔적을 포함. 버튼 자체는 회전하지 않음.
- 월 이동 도구 안의 ‘이번 달’만 검은 바탕/지면색 글씨로 반전. 이번 주/일간 버튼은 대상 아님.
- 아래 설명 영역을 동일 조건의 Noto Serif KR/조선일보명조체 비교로 변경. 새 기능/설정/데이터 필드 아님.

## 서체 비교와 의견

두 후보를 같은 폭·제목 25px·본문 15px·시간 11px·굵기 400·동일 행간으로 나란히 배치합니다. 사용자 첨부 주간 화면의 밀도는 서체뿐 아니라 제목 굵기 650과 작은 칼럼 폭도 영향을 줍니다. 현재 서체 변경 전후를 동일 굵기끼리 비교한 스크린샷이라고 주장하지 않습니다.

| 기준 | Noto Serif KR | 조선일보명조체 |
|---|---|---|
| 디자인 판단 | 더 균일하고 정돈된 인상. 여러 굵기로 제목/본문의 차이를 만들기 편함 | 가늘고 인쇄물다운 인상. 현재 사용자가 익숙한 주간 화면의 밀도를 회복하는 선택 |
| 현재 코드의 굵기 | 400/500/600/700을 요청 | 단일 웹폰트 400을 등록. 기존 650/700 표시는 브라우저 합성 굵기가 될 수 있음 |
| 구성상의 장점 | 실제 여러 굵기를 활용해 위계를 제어 | 크기/여백/색/선으로 위계를 만들고 얇은 본문을 유지하기 좋음 |
| 제안 | 굵기를 통한 위계가 최우선일 때 | 이번 프로젝트의 기본 세리프로 추천하되 아직 일괄 적용하지 않음 |

조선일보명조체 추천은 디자인 판단입니다. 서체 이름만으로 한국 종합일간지 분위기가 결정되는 것은 아니며, 현 제호·큰 여백·적은 선·제목 크기 차이를 함께 유지하는 것이 중요합니다. 특정 연령층의 취향이나 읽기 능력을 일반화하지 않습니다. 사용자 기기에서의 가독성이 객관적으로 우월하다고 단정하지 않습니다.

공식 Noto 배포는 여러 굵기를 제공합니다. [Noto Serif CJK 공식 배포](https://github.com/notofonts/noto-cjk/blob/main/Serif/README.md). 제작사는 조선일보명조체를 신문 지면용으로 개발했으며 작은 크기의 가독성을 강조합니다. 이는 제작사의 설명입니다. [조선미디어 공식 소개](https://about.chosun.com/mobile/pages/intro_ci.php). 눈누는 현재 시안과 동일한 웹폰트 코드와 웹사이트/임베딩 사용 가능 안내를 제공합니다. [눈누](https://noonnu.cc/font_page/63). 변환본 우려로 사용 중단을 요구하지 않습니다.

## 이전 결정과의 관계

사용자의 최신 부분 롤백과 비교 요청에 따라 이번 검토본은 Cormorant Garamond/Noto Serif KR/Pretendard/조선일보명조체 네 가족을 요청합니다. 이를 ‘총 두 서체만 사용하는 결과’라고 설명하지 않습니다. 이전 두 서체 요구와 동시에 충족되는 상태가 아니므로 비교 후 최종 사용 서체 수/예외 범위를 정해야 합니다. 반복 승인을 요구하지 않고 이번에 명시된 복원을 우선 적용했습니다. 손글씨 제거는 유지합니다.

## 검증과 다음 작업

스크립트 구문과 기존 모의 DOM의 7개 지표/근거/개선점/독립 저장 점검 통과. 실제 브라우저의 서체 로딩·펜 밑줄 모양·월간 반전 색·모바일 가독성은 현재 확인되지 않음. CSS 선언과 최종 렌더링은 구분합니다. 필수 지표/근거 이동/공개 안내를 유지하며 과제 RULE과 기능 충돌 없음. 완료 체크 잔여 깜박임 해결로 판정하지 않음.
