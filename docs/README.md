## 갱신 원칙

- 새 결정은 담당 문서와 현재 상태에 함께 반영합니다. 제안은 승인으로 기록하지 않습니다.
- 최신 승인과 과거 기록을 구분합니다. 과거 문서의 ‘최신/미완료’는 작성 시점의 표현입니다.
- 앱 소스 존재, 서버/DB 연결, NAS 서비스 가동, 공개 앱 배포, 사용자 검증을 각각 기록합니다.
- 최신 원격 상태를 재검증하지 않았다면 이전 작업 기록이라고 명시합니다.
- 원문 자료 사용 조건은 보존하며, 사용자 지정 예외를 외부 평가 기준 변경이라고 설명하지 않습니다.
- 실제 키·비밀번호·인증 링크·개인 접속정보는 공개 문서에 넣지 않습니다.
