## 데스크톱 핵심 흐름 검증

소스와 상태 전이 검증으로 다음 순서를 확인했습니다.

1. 계획 폴더 펼침 → 할 일 제목 선택 → 시간·기록 상세 선택
2. 완료 체크박스 변경 → 실행 기록과 독립된 완료 상태 변경
3. `시간 관리` → 기존 배치 확인·수정·삭제 및 추가 배치 접근
4. 할 일 제목 drag → 15분 단위 위치 계산 → 예상 시간 길이 미리보기
5. drop → 기존 배치 배열 변화 없음 → 확인 UI 표시
6. `배치` 선택 → 겹침이 없거나 겹침 확인 후에만 예정 블록 추가
7. `기록 시작` → `잠시 멈춤/다시 시작` → `기록 종료`
8. 기록 종료 후 할 일 완료 상태 유지

## 현재 확인되지 않은 부분

- 자동 브라우저 도구는 로컬 `file:` URL 접근을 보안 정책상 허용하지 않아 실제 화면에서의 클릭 좌표와 포인터 drag 이벤트는 자동 실행하지 못했습니다.
- 따라서 픽셀 단위 레이아웃, 실물 모바일 터치, 브라우저별 drag 감도는 현재 확인되지 않았습니다.
- 수동 검토 권장 순서: 데스크톱 1366px 이상 → 900px 부근 → 모바일 390px → 긴 타임라인 자동 스크롤 → 겹침 배치 확인.
