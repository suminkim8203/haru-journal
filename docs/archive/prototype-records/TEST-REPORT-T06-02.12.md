# T06 02.12 점검 및 검토 안내

한 줄 요약: 기존 49개와 새 삭제·복원 점검 7개, 총 56개 자동 점검이 통과했습니다. 실제 브라우저 검증은 아닙니다.

## 신규 점검

1. 일반 할 일 수정에 별도 삭제 구역 노출. 삭제 취소 시 초안과 자료 유지.
2. 삭제 후 할 일·예정 배치 숨김, 완료 상태 및 실행 기록 유지, 날짜별 실제 시간 합계 불변.
3. 삭제 항목의 새 기록·완료 변경 차단, 보존 기록 화면 접근.
4. 복원 예정 시간의 겹침 경고, 취소 시 삭제 상태 유지, 확인 시 원래 항목을 한 번만 복원.
5. 기록 중인 항목 삭제 차단 및 자료 불변.
6. 모의 삭제 저장 실패 시 원본·수정 화면 유지, 재시도 및 복원.
7. 루틴 규칙과 날짜별 항목 일괄 삭제·복원. 개별 수정·완료·실행 기록 보존.

## 검사 방법과 한계

실제 HTML 스크립트를 Node에서 실행했습니다. 문서와 저장소는 대체 객체입니다. 달력 오류를 재현했던 누락 요소 조건도 유지한 상태로 기존 검사를 다시 실행했습니다.

실제 브라우저 클릭·키보드·모바일 레이아웃은 미검증입니다. 자동 점검 통과를 실제 조작 검증 완료로 해석하지 않습니다. 로컬 파일 접근 제한을 우회하지 않았습니다.

## 검토 순서

1. 일반 계획의 할 일 선택 → 수정 → 맨 아래 할 일 삭제.
2. 확인 창에서 취소하면 초안이 유지되는지 확인하고, 다시 삭제를 진행합니다.
3. 설정 → 휴지통에서 해당 항목의 복원 또는 보존한 기록 보기를 선택합니다.
4. 루틴 계획의 수정 → 루틴 삭제에서 전체 날짜가 대상임을 확인합니다.
5. 복원 후 날짜별 완료·개별 수정 및 실제 기록이 유지되는지 확인합니다.
6. 기록 중인 항목을 삭제하려 하면 먼저 기록 종료 안내가 나와야 합니다.
