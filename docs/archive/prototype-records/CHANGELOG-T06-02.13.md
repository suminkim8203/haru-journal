# T06 02.13 — 기간 없는 루틴 계획

한 줄 요약: 일반 계획의 기간은 유지하고 루틴 계획의 기간은 제거합니다. 반복 기간은 각 할 일에서 관리합니다.

## 현재 프로젝트에 실제 구현된 기능

- 루틴 계획 생성·수정: 제목, 선택적 관리 목적, 우선순위. 계획 시작일·종료일과 전체 예상 시간 입력은 제거했습니다.
- 반복 할 일 생성: 날짜 입력은 항상 표시합니다. 처음에는 시작일 오늘, 종료일 오늘 기준 한 달 뒤를 채웁니다. 사용자가 두 날짜를 각각 수정할 수 있습니다.
- 한 달 뒤는 다음 달 같은 날짜이며 해당 날짜가 없으면 말일입니다. 예: 1월 31일 → 2월 28일(윤년 29일). 양 끝 날짜를 모두 포함합니다.
- 새 할 일에서 종료일을 직접 수정하기 전에는 시작일 변경에 맞춰 한 달 뒤로 계산합니다. 종료일을 직접 수정한 뒤에는 그 값을 유지합니다. 저장한 루틴은 날짜가 지나도 자동 연장하지 않습니다.
- 계획 기간 안에서만 반복하도록 하던 제한과 별도 반복 기간 체크박스를 제거했습니다. 종료일이 시작일보다 빠르거나 날짜가 잘못되면 저장을 막습니다.
- 루틴 계획 화면에는 일정에서 선택된 날짜와 그 날짜의 완료 수/전체 수를 표시합니다. 각 루틴은 여전히 한 줄이며 날짜별 이력은 필요할 때만 엽니다.
- 기존 루틴의 반복 날짜·예정 배치·실제 기록은 유지합니다. 이전 상위 계획 기간은 새 버전 내부의 이전 값으로 보존하지만 반복을 제한하지 않습니다.
- 별도 0213 저장 키로 접근 가능한 02.12 자료를 첫 실행 시 복사합니다. 이전 버전 저장값을 덮어쓰지 않습니다.

## 구현되지 않은 기능

- 반복 재개와 하루 건너뛰기 취소는 기존 승인 정책이지만 아직 미구현입니다.
- 종료일 없는 반복, 자동 연장, 서버 저장은 구현하지 않았습니다. 기본값만 바뀌었으며 시안의 한 번에 최대 366일 생성 제한은 유지합니다.
- 루틴 계획 자체의 기간을 없앴으므로 상위 계획 기간 변경·단축 전파 정책은 폐기합니다. 일반 계획 정책에는 적용하지 않습니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스 연결 없이 브라우저 안에서 상태가 변하는 프로토타입입니다.

## 확인이 필요한 부분

실제 브라우저 클릭·모바일 배치는 미검증입니다. 로컬 파일별 저장소가 분리되면 이전 자료를 자동으로 읽지 못할 수 있습니다. 이번 변경에 대한 자동 점검 범위는 별도 테스트 보고서에 기록합니다.
