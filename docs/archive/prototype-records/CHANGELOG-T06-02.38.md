# 02.38 — 완료 상태·시간 범위·아이콘/버튼 보정

요약: 사용자 요청 네 항목을 HTML 시안에 반영했습니다. 실제 React 앱/API/SQL은 미반영입니다.

1. 근거 오른쪽 아이콘은 글자 대신 28px SVG로 교체. 크기/모양이 본문 서체에 좌우되지 않도록 고정하며 펼침 회전/제목 전체 클릭 유지. 이전 크기 보정이 사용자 화면에서 충분하지 않았음.
2. 완료 체크와 해당 열린 기록 종료를 한 저장으로 처리. 실패 시 두 값 모두 이전 상태, 후보/재시도 시각 유지. 다른 항목의 기록은 유지. 완료한 할 일은 타이머 시작/배치·수정 차단, 수기 실행 입력/정정·단상 유지. 완료 취소 후 다시 사용 가능하되 이전 실행은 다시 열지 않음.
3. 휴식/중단 구간은 실행 시간 범위 내 분 단위 시각 선택. 전체 시간 미입력은 추가 차단, 부모 범위 변경으로 벗어난 기존 선택은 수정 안내 및 저장 검증. 자정 넘김 다음 날 표시.
4. 기록 시작 기본 버튼 160×52→128×41.6px, 글씨 17→13.6px. 모바일 폭 80%.

집중 런타임/마크업 검사 8개, 필수 보정 기존 15개, 달력/시간 차트/주간/기록 패널 회귀 검사 통과. 회귀 패널 fixture는 완료+열린 기록 모순 조건을 미완료로 고쳐 새 규칙에서 검증. 모의 DOM은 실제 브라우저/모바일 시각 검증이 아니며 사용자 기존 자료의 직접 재현은 미완료. 잔여 체크박스 깜박임을 해결 완료로 표시하지 않습니다. 과제 필수 기능과 충돌 없음, 실제 DB/배포 검증은 다음 구현에서 계속합니다.
