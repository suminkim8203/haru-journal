# 02.35 변경·검증 기록

요약: 사용자가 승인한 필수 기능 보정 네 항목을 HTML 시안에 반영했습니다. 실제 앱/API/SQL은 변경하지 않았습니다.

1. 실행별 선택 ‘막힌 이유’: 직접 입력/정정 및 타이머 종료 확인의 접힌 영역. 단상·회고에 복제하지 않음.
2. 일반 계획 결과의 막힘 수/근거: 현재 이유가 저장된 할 일을 한 번씩 집계. 제목을 펼쳐 관련 실행 확인.
3. 특정 계획 결과의 다음 계획 개선점: 기존 계획 선택 또는 같은 자리에서 새 계획 생성. 목표 유지, 출처 스냅샷/수정 이력/중복 방지.
4. 루틴 계획 기간: 생성/수정에서 입력. 반복 범위 밖이면 저장 전 안내 후 함께 확장. 과거 기록/처음 계획 보존, 자동 축소 없음.

비교 화면: Haru-required-flow-study-01.html. 예시 키 haru.required-study.v1.*는 본 시안 t06.pds.flow0224.*와 분리됩니다. 기존 본 시안 자료를 예시로 덮어쓰지 않습니다.

검증: 생성 스크립트 구문 검사 및 실제 런타임의 모의 DOM 점검 15개 통과(이유 이력·타이머 후보 시각/실패 재시도·중복 근거·개선점 스냅샷/원자 저장·공통 달력·루틴 확장/축소 방지·예시 분리). 브라우저 시각/모바일 검토 미완료. 사용자 보고 체크박스 깜박임은 해결 완료로 표시하지 않습니다.

과제 재점검: C26/C31/C33/C04 및 관련 C08/C27/C83 보정이 시안에 반영됐습니다. 실제 DB 저장/복원, 제출 자료 개수 및 집계/근거 일치, 전체 기능, 내보내기, 공개 무인증 URL, 보안/배포 증거는 실제 구현에서 계속 검증해야 합니다. 02.34 감사에서 기록한 실제 앱 미구현 사항을 완료로 바꾸지 않습니다. 더미 허용은 사용자 작업 예외이며 외부 평가 조건 변경을 의미하지 않습니다.

다음: 변경된 화면 확인 → 계약에 따른 실제 앱/API/SQL 구현 → DB 연결/통합 검증.
