# 02.23 변경 기록 및 검사

현재 시안의 문구 오류와 하루 마무리/회고 진입 흐름을 정리했습니다.

- 실행 스크립트 전반에서 단상가→단상이, 단상를→단상을, 단상와→단상과, 단상는→단상은 수정. 책갈피 필터 안내는 '책갈피에 표시한 회고만 보기'. 완료 체크는 목록 또는 상세에서 할 수 있다는 안내로 수정했습니다. 과거 내장 참고 시안 및 사용자가 이미 저장한 글은 일괄 치환하지 않았습니다.
- 책갈피 바깥 네모/배경 제거. 둥근 상단, 얇은 선의 리본 SVG와 채움 상태를 사용합니다. 키보드 초점 표시는 유지합니다.
- 돌아보기는 계획 결과/날짜별 시간 사용만 제공합니다. 회고 작성은 일정의 하루 마무리, 열람/수정은 보관함으로 연결합니다.
- 하루 마무리 안내: '단상을 확인하고 회고를 작성할 수 있습니다.' 클릭 후 기존 시작 버튼을 숨기며 미완료 할 일 수부터 보여줍니다. 단계 설명 제거, 회고 작성 버튼 우측 정렬. 열린 기록은 먼저 종료해야 합니다.
- 회고 입력에서 관련 계획 수동 선택을 제거했습니다. 가져온 단상의 출처/기존 계획 연결은 보존합니다. 기존 입력 힌트에 작성 없이 마무리 가능하다는 문장을 추가했습니다.
- 마무리 후 일정의 같은 자리에서 완료 상태를 보여줍니다. 작성된 회고가 있을 때만 저장한 회고 보기 링크로 보관함에 연결합니다.
- dayClosures에 날짜별 마무리 상태를 저장합니다. 빈 내용으로 마무리하면 새 reflection을 만들지 않습니다. 기존 빈 회고는 자료에 보존하되 회고 모음에서 숨깁니다. 기존 회고를 빈 글로 덮어쓰려 하면 삭제 메뉴를 안내합니다.

검사 45개 통과: 신규 흐름/문구/실패 보호 6, 이전 단상/인라인 편집/공유 달력 8, 주간 10, 루틴 14, 휴지통 7. 실제 실행 코드를 대체 DOM에서 확인했습니다. 시각/모바일/달력 팝업 배치는 실제 브라우저에서 확인하지 못했습니다.

저장 키 flow0223으로 접근 가능한 flow0222 자료를 최초 복사합니다. 이전 파일과 저장 자료를 덮어쓰지 않습니다. 실제 파일 URL 간 자료 공유는 미확인입니다. 서버/DB/배포는 추가하지 않았습니다.

다음 사용자 확인: 하루 마무리의 단계 전환, 글 없이 완료하기, 작성한 회고를 보관함에서 보기, 책갈피 아이콘. 확인 후 화면 변경 사항을 확정하고 실제 구현용 데이터 계약 정리로 진행합니다.
