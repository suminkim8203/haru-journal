## 3. 수정·삭제 관계 — 사용자 승인

- 계획 삭제: 소속 할 일·루틴·예정 배치를 휴지통으로. 실행 기록·단상·회고 보존.
- 할 일 삭제: 예정 배치도 휴지통으로. 과거 실행 기록·단상 보존.
- 루틴 변경: 이미 실행한 날짜는 유지, 이후 일정에 적용.
- 단상 변경: 이미 저장한 회고에 영향 없음.
- 회고 수정: 동일 회고 갱신, 책갈피 상태 유지.
- 회고 삭제: 휴지통 이동, 원래 단상 보존.
- 복원 시 예정 겹침 또는 같은 날짜 회고가 있으면 덮어쓰지 않고 안내.
- 삭제된 출처의 이름은 기록에 보존. 위 정책 모두가 현재 시안에 완성되었다는 뜻은 아니며 서버 구현 계약임.

회고는 계획에 속하지 않는 날짜별 기록입니다. 보관함 계획 필터를 제거하며 날짜/내용/책갈피로 조회합니다. 기존 planIds는 과거 출처 정보로 보존하지만 접근·소유·삭제 종속 관계로 사용하지 않습니다.

회고 본문 또는 일간 보기 버튼은 회고 날짜의 일간으로 이동합니다. 삭제된 계획이 있어도 이동을 막거나 잘못된 계획 오류를 표시하지 않습니다. 책갈피/수정/삭제는 독립 조작입니다. 삭제된 계획·할 일을 직접 여는 경우에는 해당 자료 삭제 상태를 안내하는 기존 흐름과 구분합니다.

Noto Serif KR/손글씨 제외. 입력/좁은 목록/숫자는 Pretendard, 단일 명조 400 및 합성 금지. outputs/Haru-typography-study-01.html에서 같은 내용의 주간/회고/단상/입력/집계, 동일 조건과 조정 후보, 1100/390/360px 비교 가능. 추천 가설 A이며 최종 승인/전체 적용 아님. 본 기능 시안 02.39/기존 디자인 검토 03/실제 앱/API/DB 미변경. 실제 WOFF 메타데이터 두 파일 검사: Regular 400, 가변 아님. 구문/10개 후보·화면 모의 DOM 점검 통과. 직접 브라우저 렌더링/모바일 기기/폰트 로딩 확인은 접근 제한으로 미완료. 자세한 분류/7열 표/설계 의견/검증 한계는 TYPOGRAPHY-ROLE-STUDY-01.md. 다음은 실제 로딩 및 두 단계의 읽기 확인 후 A/B와 조정값 결정.

## 날짜 역할 예외 승인 — 디자인 검토 05

사용자는 일간 날짜 줄 C안을 선택했습니다. 요일은 메뉴 역할의 조선일보명조, 숫자와 작은 ‘오늘’ 표시는 Pretendard를 유지합니다. 별도 크기 선택이 없으므로 기존 크기·간격을 유지했습니다. 돌아보기 날짜별 시간 사용의 큰 월.일–월.일 범위는 제목 역할로 조선일보명조 400을 적용합니다. 숫자를 일괄 세리프로 바꾸자는 내용은 고민이며 아직 승인이 아닙니다. 캘린더·주간·월간·집계·기록 시간의 다른 숫자는 변경하지 않습니다.

계획 결과의 선택 지표 밑줄은 바랜 버건디 #75444b, 주 획 2.2→1.6으로 약 27% 가늘게 변경했습니다. 보조 획 .8과 기존 곡선 형태·폭·선택 동작 유지. 최신 검토본 outputs/Haru-design-study-05.html이며 04/본 기능 시안 02.39/실제 앱/API/DB는 미변경입니다. 새로운 서체·기능·데이터 결정 없음, 필수 집계·근거 이동·공개 안내 유지, 과제 RULE 충돌 없음. 구문 및 기존 모의 DOM 기능 점검 통과, 실제 브라우저/폰트 로딩/시각 결과 미확인. 다음은 일간 날짜 줄·돌아보기 날짜 범위·선택 밑줄 확인 후 실제 앱 이식으로 진행.
