# T06 02.11 변경 기록

한 줄 요약: 계획 화면을 루틴별 목록으로 바꾸고, 새 루틴의 기간은 계획 기간을 기본값으로 사용하도록 간소화했습니다.

## 현재 프로젝트에 실제 구현된 기능

- 계획 화면: 반복할 일 하나당 한 줄. 날짜별 할 일 전체 나열을 제거했습니다.
- 루틴 제목 검색과 20개 단위 페이지 이동. 완료 체크박스 대신 수정/날짜별 이력 접근을 제공합니다.
- 날짜별 이력은 루틴 하나를 선택해야 열립니다. 기본 7일, 조회 기간 변경, 최대 20개씩 페이지 이동.
- 날짜별 이력에서 일간 보기로 이동하면 해당 날짜의 항목을 선택합니다. 완료·기록·건너뛰기는 일간에서 처리합니다.
- 계획의 수정은 반복 규칙 수정으로 연결합니다. 현재 또는 이후 첫 날짜부터 적용하며 과거·완료·실행·개별 예외를 보존합니다. 적용 대상 확인을 거쳐 저장합니다.
- 날짜별 이력으로 돌아보기 근거 연결을 유지했습니다.
- 새 루틴은 계획 기간과 동일이 기본입니다. 날짜 입력은 숨기고 기간을 요약해서 표시합니다.
- 이 할 일의 반복 기간 따로 설정을 선택하면 시작일·종료일 입력이 나타납니다.
- 다시 계획 기간을 선택하면 별도 날짜 입력 및 오류를 지우고 해당 계획의 날짜를 사용합니다.
- 일반 상태에서 계획 시작일/계획 종료일이라는 별도 단축 버튼은 제거했습니다. 잘못된 날짜의 구체적인 오류 안내는 유지합니다.
- 기존 밝은 기록 종료 버튼과 패널에 이어지는 sticky 하단 영역은 유지합니다.

## 구현되지 않은 기능

- 부모 계획 기간 변경을 모든 기존 루틴에 자동 전파하는 기능은 추가하지 않았습니다. 이번의 계획 기간 기본 사용은 생성 시 날짜를 중복 입력하지 않는 동작입니다. 기존 기록 보호와 기간 변경 범위의 확인 흐름은 별도 정책 검토가 필요합니다.
- 루틴 재개, 건너뛰기 취소, 요일별 반복, 서버·DB 기능은 이번 범위 밖입니다.
- 내부 날짜별 자료는 계속 보존합니다. 서버에서 필요한 날짜만 생성하는 지연 생성 설계는 실제 개발 단계의 별도 과제입니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스 연동 없음. 브라우저 임시 저장을 사용하는 HTML 시안입니다.

## 확인이 필요한 부분

- 실제 데스크톱/모바일의 시각 배치와 클릭·키보드 조작은 미검증입니다.
- 반복 규칙 변경의 기준일은 현재 또는 이후 첫 날짜로 자동 선택하고 화면에 표시합니다. 임의 적용 시작일 선택 UI는 추가하지 않았습니다.
- 계획 화면의 루틴 목록과 이력 분리가 이해하기 쉬운지 사용자 검토가 필요합니다.
