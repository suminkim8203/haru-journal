# 02.22 변경 기록 및 검증

단상을 실제 실행이 있는 할 일·선택 날짜별 하나로 축소하고 회고 인라인 편집과 공유 달력을 적용했습니다.

- 단상은 ui.date의 실제 실행 구간이 존재하는 할 일에서만 표시합니다. 진행 중 실행도 포함합니다. 계획 화면과 예정만 있는 할 일에는 단상 입력을 제공하지 않습니다.
- 단상의 날짜 입력을 제거했습니다. 저장된 글이 있으면 본문과 수정만 보이고, 글이 없거나 수정할 때만 작은 입력창이 표시됩니다.
- 기존 여러 글은 같은 할 일·날짜별 한 본문으로 모아 읽습니다. 수정 저장은 단일 dayThought 자료를 생성/갱신하고 원본 ID를 기록해 중복 표시를 막습니다. 원래 실행 note와 이전 단상 자료는 삭제하지 않습니다. 기존 계획 단상은 저장 자료에 보존하되 새 작성/가져오기 흐름에서는 제외합니다.
- 회고 모음의 전체 버튼을 제거하고 책갈피 필터 토글 아이콘 하나로 대체했습니다. 회고 카드의 책갈피 추가/해제도 아이콘이며 aria-label/title/aria-pressed를 제공합니다.
- 보관함 탭 변경 시 goFocus/scroll 이동을 제거했습니다.
- 회고 수정은 원래 카드 안에서 열리고 저장/취소 후 같은 목록으로 돌아옵니다. 별도 상단 편집 영역으로 이동하지 않습니다.
- 기존 date-dialog 달력을 재사용합니다. 아직 남아 있던 native date 입력은 같은 날짜 선택 버튼으로 연결하고 기존 input/change 흐름과 범위 검사를 유지합니다. 읽기 전용 날짜는 변경 불가입니다.
- 헤더 오른쪽 ‘틈틈이’를 삭제했습니다. 이름 ‘하루의 여백’은 여전히 미확정 작업명 후보입니다.

검사: 신규 8개(실행/날짜 범위, 입력창 축소, 단일 저장과 원문 보존, 메뉴 이동, 인라인 저장, 실패 초안 보존, 공통 달력 범위/이벤트, 화면 함수 초기화) + 주간 10 + 루틴 14 + 기존 휴지통 7 = 39개 통과. 실제 실행 스크립트를 대체 DOM에서 검사했습니다. 실제 화면 크기, 달력 팝업 위치, 모바일 터치, SVG 책갈피 인지성, 스크롤 앵커 동작은 확인되지 않았습니다.

02.22는 독립 flow0222 저장 키를 사용하고 접근 가능한 flow0221 자료를 최초 복사합니다. 이전 파일은 보존했습니다. file URL 간 실제 자료 공유 여부는 미확인입니다. 서버/DB/외부 서비스 기능은 추가하지 않았습니다.

다음 확인: 실제 실행한 할 일에서 선택 날짜의 단상 저장/수정, 카드 안 회고 수정, 책갈피 필터, 회고/보관함의 공통 달력. 승인 후 남은 화면 문제를 마무리하고 실제 구현용 데이터 구조 정리로 진행합니다.
