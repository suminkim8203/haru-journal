## 구현되지 않은 기능

### 승인된 요구사항 — 개발 및 추가 검토 목록

- R-01 반복 재개: 재개 날짜 선택, 중단 기간 소급 생성 없음, 같은 날짜 중복 생성 없음.
- R-02 건너뛰기 취소: 해당 날짜와 이전 배치 복원, 겹침 확인, 실행 기록 변경 없음.
- 두 기능 모두 동작 원칙은 승인됐지만 진입 위치·확인 화면은 아직 시안 검토 전입니다.

### 실제 개발 전 준비 항목

- 사용자 유형, 자료 소유권, 타인 열람·공유·공동 수정 범위.
- 저장 위치, 기기 간 동기화 필요 여부, 오프라인 사용 범위.
- 위 결정에 따른 계정 절차와 권한 검증 설계. 회원가입·초대·이메일 확인·계정 활성화·최초 비밀번호 설정·변경·재설정은 별개 절차로 판단합니다. 모두 필요하다고 가정하지 않습니다.
- 데이터 관계와 보존·복구 정책, 충돌 처리, 운영·배포 조건.

### 폐기 또는 제외된 안

- 폐기: 루틴 계획 자체 기간, ‘계획 기간과 동일’ 선택, 상위 계획 기간 변경·단축 전파 정책.
- 이번 시안 제외: 종료일 없는 반복, 자동 연장, 블록 크기 드래그 조절, 영구 삭제.
- 366일 생성 제한은 시안 제약이며 실제 서비스 정책으로 확정하지 않았습니다.

## 서비스가 지원하지만 현재 사용하지 않는 기능

외부 서비스 미연결. 특정 공급자의 기능·요금·한도는 조사하거나 선택하지 않았습니다. 브라우저 저장을 서버 저장, 계정별 보안, 백업 또는 기기 간 동기화로 설명하지 않습니다.

## 확인이 필요한 불확실한 부분

### 검증 대기

- 실제 브라우저에서 데스크톱 클릭, 드래그 확인·취소·겹침·스크롤.
- 모바일 목록·날짜 입력·확인 창 및 키보드 접근.
- 재개/건너뛰기 취소와 중단·휴지통 등 상태가 겹치는 경우.
- 저장 실패·여러 창 충돌의 실제 환경 동작과 기록 보존.
- 02.13 자동 검사 14개는 제한된 대체 문서 환경 검사입니다. 02.12의 56개 전체 검사를 02.13에서 재실행한 결과가 아닙니다.

### 경미한 개선 관리 원칙

정렬·여백·색·문구 등 추가 피드백은 재현 화면과 기대 결과를 기록해 개발 단계에서 묶어 처리합니다. 현재 확인하지 않은 결함을 발견된 버그처럼 기재하지 않습니다. 달력 열기 실패처럼 검토를 막는 문제나 기록·집계 오류는 즉시 수정 대상으로 분리합니다.

### 다음 결정 — 추천이며 미확정

첫 버전을 개인용으로 제한할지, 공유·공동 관리를 포함할지 먼저 확인합니다. 개인용을 택하더라도 브라우저 전용인지 계정 기반 여러 기기 사용인지는 별도 결정입니다. 화면 시안에 문구나 내부 자료 구조가 존재한다는 이유만으로 접근 권한 정책을 추론하지 않습니다.
